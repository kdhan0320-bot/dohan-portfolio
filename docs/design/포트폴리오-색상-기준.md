# 포트폴리오 색상 기준

공통 포트폴리오의 현재 밝은 중성 배경·차콜 글자·더스티 블루를 기준으로 관리합니다. 품의선·잔상관·갈피록 등 개별 작품의 색을 이 팔레트로 일괄 교체하지 않습니다. 기준 코드는 [theme.js](../../lecture1/portfolio/src/theme.js)입니다.

## 현재 색과 역할

| 역할 | 색 | 사용 |
| --- | --- | --- |
| 페이지 배경 | #F7F7F4 | 넓은 읽기 영역 |
| 카드 표면 | #FFFFFF | 화면·전표·이미지를 받치는 면 |
| 제목과 본문 | #252826 | 핵심 내용 |
| 보조 글자 | #535D60 | 설명·메타 정보 |
| 주요 조작 | #45657B | 버튼·링크·강조 |
| 어두운 강조 면 | #233746 | 표지 버튼 등 |
| 구분선 | #D4D9D7 | 장식적 경계, 글자색으로 사용하지 않음 |

## 읽기 대비

계산은 sRGB 상대 휘도 공식과 불투명 단색 조합을 사용했습니다. 표는 소수 둘째 자리로 표시하며 실제 판정은 반올림 전 값으로 합니다. 이미지·투명도·호버·포커스·비활성 상태는 화면에서 별도로 확인합니다.

| 글자 / 배경 | 대비 | 일반 크기 글자 |
| --- | ---: | --- |
| #252826 / #F7F7F4 | 13.87:1 | 충족 |
| #535D60 / #F7F7F4 | 6.31:1 | 충족 |
| #FFFFFF / #45657B | 6.18:1 | 충족 |
| #45657B / #F7F7F4 | 5.75:1 | 충족 |
| #FFFFFF / #233746 | 12.31:1 | 충족 |

일반 텍스트와 일반 크기의 버튼 글자는 4.5:1 이상을 적용합니다. 큰 글자는 3:1 이상이며, 일반 굵기 18pt 또는 굵은 14pt 이상이라는 크기 조건이 있습니다. 조작·상태를 식별하는 비텍스트 시각 정보에는 인접 색과 3:1 기준이 적용됩니다. 장식선과 비활성 요소의 예외를 입력 안내 글자에 임의 적용하지 않습니다. [W3C 텍스트 대비](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) · [W3C 비텍스트 대비](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)

## 이전 문서 평가

역할별 색상 변수와 사용 예시를 정리한 점은 참고할 만합니다. 다만 현재 포트폴리오의 구현 기준으로 그대로 사용하기에는 내용이 맞지 않습니다.

- #8A9BB5 배경과 흰 글자를 금지 조합과 권장 조합에 동시에 적었습니다. 실제 대비는 2.82:1입니다.
- 밝은 블루 #1E9BD7 위의 흰 글자는 3.12:1로 일반 크기 버튼 글자 기준을 충족하지 않습니다. 골드 #FFB800 위의 흰 글자는 1.73:1입니다.
- #8A9BB5 배경과 #555555 글자는 2.64:1입니다. 배색 인상과 가독성은 별도로 판단해야 합니다.
- 버튼 글자에 일률적으로 3:1을 적용한 체크리스트는 수정해야 합니다.
- 배경 55%·포인트 8%처럼 고정한 비율에는 작품별 정보량이나 검증 근거가 없습니다. 화면의 역할과 위계로 판단합니다.
- 사용하지 않는 자동 다크모드와 복사하기 어려운 끊어진 CSS 예시가 섞여 있습니다. 새 기능의 구현 근거로 사용하지 않습니다.

밝은 파랑·골드 조합 자체가 나쁜 것은 아닙니다. 현재의 종이 표지·전표·차분한 편집 방향에는 현재 중성 배경과 낮은 채도의 블루가 더 일관된 선택이라는 디자인 판단입니다. 색만으로 독창성이 생기는 것은 아니며, 표지 펼치기·전표 흐름·타이포그래피·작품 배치와 함께 평가해야 합니다.

## 수정할 때 확인할 항목

- 주요 행동과 상태를 색만으로 전달하지 않고 글자·아이콘을 함께 둡니다.
- 투명도·사진 위 글자·호버·포커스 상태의 실제 배경까지 확인합니다.
- 모바일과 PC에서 글자 크기·줄바꿈·버튼 인식이 유지되는지 확인합니다.
- 새 색상은 역할과 대비를 기록한 뒤 추가합니다. 실제 화면의 전체 접근성 검증 결과와 이 단색 계산을 구분합니다.
