# 클로드 교차 검토 안내

같은 작업을 다른 관점에서 검토하되, 지적 사항은 현재 코드와 실제 화면에서 확인합니다. 두 AI의 의견이 같다는 이유만으로 검증된 사실로 간주하지 않습니다.

## 열어 둘 작업 폴더

기존 웹 작품은 D:\Archive\my_ai_web\portfolio-workspace를 작업 폴더로 엽니다. 공통 포트폴리오는 lecture1/portfolio, 품의선은 lecture1/pumuiseon입니다. 나머지 작품 경로와 공개 주소는 [작업 안내](../README.md)를 따릅니다.

새 AI 작품은 D:\Archive\my_ai_web\ai-projects 아래 해당 프로젝트 폴더에서 검토합니다. 클로드 웹 채팅처럼 로컬 폴더 접근이 없는 환경에서는 현재 변경 내역·관련 파일·화면 자료를 제공해야 합니다. 로컬 설정과 인증정보를 포함한 전체 폴더를 업로드하지 않습니다.

## 진행 순서

1. 수정 담당이 작업을 마친 뒤 현재 branch·HEAD·미반영 변경을 알려줍니다. 작업이 끝나기 전에 검토 담당에게 같은 파일을 수정하게 하지 않습니다.
2. 검토 담당은 기존 설명을 결론으로 삼지 않고 코드·화면·검사 결과를 확인합니다. 먼저 소스 변경 없이 문제와 근거를 보고합니다.
3. 실제 결함, 사용성 개선, 취향 제안을 나눕니다. 확인하지 못한 DB 동작·브라우저·Figma 범위는 따로 적습니다.
4. 수정할 항목이 정해지면 한쪽이 반영하고 관련 검사를 수행합니다. 기존 사용자 승인 범위에 따라 커밋·배포합니다.

## 복사해서 요청할 문장

아래에서 대상 작품과 변경 범위를 실제 작업에 맞게 바꿔 전달합니다.

> 이 작업 폴더의 CLAUDE.md·AGENTS.md와 대상 작품 README를 먼저 읽고 교차 검토해 주세요. 대상 작품은 [작품 폴더], 확인할 변경은 [변경 내용]입니다. 먼저 현재 branch·HEAD·미반영 변경을 확인하고 소스를 수정하지 않은 채 검토 결과를 알려주세요. 문제가 있으면 중요도, 재현 방법, 실제 파일 위치 또는 화면·주소·화면 폭, 사용자 영향을 적어주세요. 결함과 취향 제안을 구분하고, 실제 실행한 검사와 확인하지 못한 범위를 따로 알려주세요. 확인되지 않은 본인 기여나 성과를 추가하지 말아주세요.

## 결과를 판단할 기준

같은 문제를 재현할 수 있는지, 관련 코드와 화면 근거가 있는지, 수정이 다른 기능을 깨뜨리지 않는지 확인합니다. 막연한 점수나 칭찬보다 이 세 가지가 유용합니다. 화면 검수는 원본 크기 캡처를 보고 판단하며, 자동 검사 통과와 시각 검토를 구분합니다.

CLAUDE.md는 검토 방향을 전달하는 안내입니다. 소스 변경을 기술적으로 차단하는 권한 설정은 아닙니다. 사용 중인 클로드 환경에서 안내가 읽혔는지 확인합니다. [Claude Code 공식 안내](https://code.claude.com/docs/en/memory)
