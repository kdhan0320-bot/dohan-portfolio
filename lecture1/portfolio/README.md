# 공통 포트폴리오

웹·UI 디자인 소개, 작품 상세, 확인된 본인 기여입니다.

[공개 사이트](https://kdhan0320-bot.github.io/dohan-portfolio/my-portfolio/)

## 실행과 검사

이 작품 폴더에서 실행합니다.

```powershell
npm ci
npm run dev -- --host 127.0.0.1
npm run lint
npm run build
```

## 파일 안내

- src: 현재 화면과 동작 코드
- public: 주소로 제공되는 이미지·글꼴
- package-lock.json: 설치 버전 기록
- dist: 빌드 결과, 직접 수정하지 않음

본인 기여와 AI 지원 범위를 구분합니다. 프로젝트 상세의 공개 URL과 hash 경로는 폴더명 변경 후에도 유지합니다.

## 버튼·링크 표현 정리 — 2026-11-08

문구가 행동을 충분히 설명하는 버튼과 링크에는 장식 화살표를 반복하지 않는다는 사용자 기준을 적용합니다.

대표 작업·기준선 소개·그 밖의 작업·품의선 사례·모바일 배정 시안 링크의 장식 화살표를 제거했습니다. 그 밖의 작업은 화살표 전용 열을 없애고 두 열로 정렬합니다. 담당자 선택 펼치기는 +/−로 상태를 구분합니다. 기존 프로젝트 데이터와 진행 중인 다른 수정은 보존합니다.

## 아이콘·장식 정리 — 2026-11-08

## 현재 홈의 설계 기준 — 2026-11-12 전면 개편

대상은 지원 분야·대표작·본인 기여를 빠르게 파악해야 하는 채용 담당자입니다. 사용자가 지적한 문제는 정적인 첫인상, 약한 시각 대비, 레퍼런스와 비교해 변화가 작았던 작품 구성이었습니다. 이번 구현은 아래 규칙을 따릅니다.

- **첫인상:** “일의 순서를, 화면의 질서로.”를 두 줄의 큰 제목으로 사용합니다. 구매·총무·생산 현장 경험을 정렬되는 선으로 연결합니다. 별도 입장 클릭 없이 제목과 선이 바로 움직이며 작품으로 스크롤할 수 있습니다.
- **작품 구성:** 품의선·설비결·잔상관을 같은 순서(대표 이미지 → 제목·의도 → 확인된 기여)로 읽게 합니다. 기준선·갈피록·온정류·소요빛은 두 열 이미지 목록으로 구분합니다. 모바일에서는 한 열로 이어집니다.
- **색과 대비:** 배경 `#25272A`, 본문 `#F2F1ED`, 보조 글자 `#B4B7BE`, 작은 강조 `#B6C4E5`. 배경 대비 본문 13.25:1, 보조 글자 7.46:1, 강조색 8.57:1입니다. 경험 소개는 조금 밝은 차콜 `#2E3034`로 구분하며 작품의 원래 색은 보존합니다. 수치는 해당 단색 조합의 계산값이며 모든 이미지·상태의 접근성 인증을 뜻하지 않습니다.
- **모션:** 제목의 순차 진입, 자동으로 모이고 흐르는 선, 마우스 위치 반응, 작품의 일회성 스크롤 등장과 호버를 사용합니다. 선은 멈추기/재생이 가능하고 화면 밖·숨겨진 탭에서는 렌더링을 쉬도록 구현했습니다. 움직임 감소 설정에서는 처음부터 정지하며 사용자가 재생을 선택할 수 있습니다.
- **참조와 차이:** [김도훈](https://www.designerhoon.com/)에서는 큰 글자와 일관된 작품 목록, [AJS](https://ajs.kr/)에서는 접속 직후 느껴지는 모션과 하나의 시각 주제를 참고했습니다. 그래픽은 현장 업무 흐름을 해석해 새로 구현했으며 참조 사이트의 문구·이미지·코드를 복사하지 않았습니다. 별도 인트로 입장 화면은 작품 접근을 한 번 더 누르게 하므로 사용하지 않습니다.
- **기여와 한계:** 확인된 업무 경험·요구사항·우선순위·방향 선택과 AI의 시각 제안·Figma 편집·웹 구현을 구분합니다. 독립적으로 직접 그린 전후 시안이나 사용자 조사·취업 성과를 새로 만들지 않았습니다. 주목도·이해 속도 향상은 실제 관찰로 추가 확인할 사항입니다.

## 소프트 차콜 적용 — 2026-11-12 현재 색상

사용자가 전체 색이 아쉽다고 지적하고, 실제 홈에 적용한 소프트 차콜 미리보기를 승인했습니다. 기존 첫 화면·작품 순서·확인된 기여를 유지하면서 홈·목록·소개·상세 7개·없는 경로 안내까지 같은 색 규칙을 적용합니다.

- 김도훈 레퍼런스의 큰 글자와 일정한 작품 목록은 유지합니다. AJS의 어두운 무채색 바탕과 밝은 모션에서 대비 방식을 참고하고, 이번에는 사용자 요청에 맞춰 `#25272A`의 상대적으로 밝은 차콜을 사용합니다. 두 사이트의 자산·문구·코드는 복제하지 않았습니다.
- 제목과 주요 버튼은 중성색으로, 작은 강조와 링크 상태는 청회색으로 한정합니다. 파스텔 작품 표지 배경은 각 작품 색을 낮은 채도로 이어갑니다. 실제 웹/Figma 이미지와 설비결의 밝은 선택 시연은 원래 색을 유지합니다.
- 밝은 전표 아래 캡션, 입출고 수량, 제작 기여 카드, 담당자 선택 주변, 소개의 연락 버튼까지 대비를 조정했습니다. 필터는 글자와 배경이 동시에 회색으로 흐려지지 않도록 선택 색과 숫자를 즉시 전환합니다.
- 색상 기준은 `src/index.css`, UI 기본값은 `src/theme.js`에서 관리합니다. 선 그래픽도 CSS 색상을 읽으며, 시작 배경·브라우저 테마색·탭 아이콘을 같은 계열로 맞췄습니다. 이미지 자체를 어둡게 필터 처리하지 않습니다.
