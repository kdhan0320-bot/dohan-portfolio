# 공통 포트폴리오

웹·UI 디자인 소개, 작품 상세, 확인된 본인 기여입니다.

[공개 사이트](https://kdhan0320-bot.github.io/dohan-portfolio/my-portfolio/)

## 실행과 검사

이 작품 폴더에서 실행합니다.

```powershell
npm ci
npm run dev -- --host 127.0.0.1
npm run lint
npm run build
```

## 파일 안내

- src: 현재 화면과 동작 코드
- public: 주소로 제공되는 이미지·글꼴
- package-lock.json: 설치 버전 기록
- dist: 빌드 결과, 직접 수정하지 않음

본인 기여와 AI 지원 범위를 구분합니다. 프로젝트 상세의 공개 URL과 hash 경로는 폴더명 변경 후에도 유지합니다.

## 2026-11-07 잔상관 소개 보완

- 실제 요청 기록에 근거해 단독 표지·분위기와 시간 통합·검색 초기화·메모 읽기와 편집 구분을 판단 사례로 제시합니다.
- 화면 배치·장면 선정·문구·이미지 제작·구현·검사는 AI 협업 범위로 표시합니다. 사용자 조사·채용 성과를 수행한 것처럼 설명하지 않습니다.
- 최신 보관함과 메모 읽기 캡처를 PC·모바일로 제공합니다. 잔상관 소개의 두 PC 화면에만 같은 너비를 적용하며 공통 포트폴리오 구성은 유지합니다.

## 버튼·링크 표현 정리 — 2026-11-08

문구가 행동을 충분히 설명하는 버튼과 링크에는 장식 화살표를 반복하지 않는다는 사용자 기준을 적용합니다.

대표 작업·기준선 소개·그 밖의 작업·품의선 사례·모바일 배정 시안 링크의 장식 화살표를 제거했습니다. 그 밖의 작업은 화살표 전용 열을 없애고 두 열로 정렬합니다. 담당자 선택 펼치기는 +/−로 상태를 구분합니다. 기존 프로젝트 데이터와 진행 중인 다른 수정은 보존합니다.
