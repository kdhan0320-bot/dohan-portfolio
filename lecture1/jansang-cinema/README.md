# 잔상관

가상 단편영화 탐색·찜·메모 보관 시연입니다.

[공개 사이트](https://kdhan0320-bot.github.io/dohan-portfolio/jansang-cinema/)

## 화면을 정한 기준

- 제목을 정하지 않은 이용자가 분위기와 남는 시간으로 단편영화를 고르는 상황을 가정합니다. 홈에서는 ‘파란 오후’ 한 편을 먼저 보여주고 바로 아래에서 조건을 선택합니다.
- 한글과 문장부호의 형태가 섞이지 않도록 홈 제목은 문구 전체를 지원하는 Pretendard로 표시합니다. 영화 잡지의 편집 방향은 기획전의 두 장면과 그 관계를 설명하는 한 줄로 표현합니다.
- 이용안내는 가상 콘텐츠·브라우저 저장·초안 보존 범위에 집중합니다. AI 포스터 시안과 제목 표현에 관한 제작 설명은 작품 소개에서 확인할 수 있습니다.

- 홈 기획전은 ‘파도와 물길, 그다음은 대화’로 듣는 대상이 바뀌는 선정 관점을 드러냅니다. 표지의 한 편과 기획전의 두 장면은 서로 다른 역할을 갖습니다.
- 새 표지 이미지는 AI가 기존 시안의 반사광과 질감을 편집한 결과입니다. 생성 표현이 없어졌거나 직접 촬영·수작업한 원화라고 설명하지 않습니다.

## 보관함의 읽기 기준

- 확인한 문제: PC에서 메모 없는 작품도 한 줄 전체를 차지해 작품 정보 옆에 빈 공간이 크게 남았습니다.
- 목록·키보드 순서를 유지하면서 메모 없는 이웃 작품을 두 편씩 묶습니다. 메모가 있는 작품과 짝이 없는 작품은 한 줄을 사용하고, 1100px 이하에서는 한 편씩 표시합니다.
- 관심 메모는 저장본을 먼저 읽고 수정 버튼으로 편집합니다. 이는 김도한이 요청한 흐름이며, 구체적인 카드 배치와 코드는 AI와 구현했습니다. 작품 훑기 보기와 브라우저 저장 형식은 유지합니다.
- 단독 표지의 작은 프레임 표시는 로고·기획전의 겹친 프레임과 연결했습니다. 새 섹션이나 반복 움직임을 추가하지 않았습니다.

## 실행과 검사

이 작품 폴더에서 정적 서버를 실행하고 http://127.0.0.1:4178/을 엽니다.

```powershell
python -m http.server 4178 --bind 127.0.0.1
```

## 파일 안내

- index.html 및 다른 HTML: 페이지 구성
- css·js: 스타일과 상호작용
- assets: 이미지·글꼴 및 출처 자료

가상 영화 12편을 탐색하고 찜·메모를 브라우저에 저장합니다. 실제 영상 재생·예매·결제 서비스가 아닙니다.
