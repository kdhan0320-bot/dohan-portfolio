# 기준선

Figma 기반 산업용 비전 검사 기업 웹퍼블리싱입니다.

[공개 사이트](https://kdhan0320-bot.github.io/dohan-portfolio/gijunseon/)

## 실행과 검사

이 작품 폴더에서 정적 서버를 실행하고 http://127.0.0.1:4178/을 엽니다.

```powershell
python -m http.server 4178 --bind 127.0.0.1
```

## 파일 안내

- index.html 및 다른 HTML: 페이지 구성
- css·js: 스타일과 상호작용
- assets: 이미지·글꼴 및 출처 자료

기존 Figma 작품을 구현한 가상 기업 사이트입니다. 상담은 브라우저 시연이며 실제 접수·주문 시스템과 구분합니다.
