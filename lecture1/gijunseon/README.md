# 기준선

Figma 기반 산업용 비전 검사 기업 웹퍼블리싱입니다.

[공개 사이트](https://kdhan0320-bot.github.io/dohan-portfolio/gijunseon/)

## 실행과 검사

이 작품 폴더에서 정적 서버를 실행하고 http://127.0.0.1:4178/을 엽니다.

```powershell
python -m http.server 4178 --bind 127.0.0.1
```

## 파일 안내

- index.html 및 다른 HTML: 페이지 구성
- css·js: 스타일과 상호작용
- assets: 이미지·글꼴 및 출처 자료

기존 Figma 작품을 구현한 가상 기업 사이트입니다. 상담은 브라우저 시연이며 실제 접수·주문 시스템과 구분합니다.

[기존 제작 이력과 검증 범위](docs/HISTORY.md)에 이전 README를 보존했습니다. 당시 기록과 현재 상태는 구분해서 읽습니다. [작업공간 안내](../../README.md)에서 폴더·공개 주소·배포 절차를 확인할 수 있습니다.

## 설계 근거와 제작 범위

- 대상과 목적: 비전 검사를 처음 검토하는 제조 현장의 담당자가 검사 대상, 적용 위치, 도입 전 준비 자료를 차례로 살펴보는 가상 기업 사이트입니다. 실제 사용자 조사로 검증한 수요나 성과를 뜻하지 않습니다.
- 관찰한 문제: 반복 검수에서 Figma의 PC·모바일 숫자 표식과 웹의 표현이 달랐고, 진한 격자가 본문·도식과 경쟁했습니다. 같은 단계는 같은 번호·초점 모서리로 표시하고, 격자는 어두운 안내 영역에만 선 6%·점 18%로 제한했습니다.
- 정보 구성: 제품과 결함을 먼저 보고 → 적용 공정을 이해하고 → 도입 절차와 준비 자료를 확인한 뒤 상담으로 이동합니다. 검사 선택은 상담에도 이어져 같은 항목을 다시 고르지 않게 합니다.
- 반응형: 콘텐츠가 좁아지면 사진과 설명을 세로로 재배치하고 모바일 메뉴를 제공합니다. Figma 대표 모바일은 390px이며 웹은 320px부터 유동적으로 표시합니다.
- 버튼 마감: 사용자가 지적한 글자 중심의 어긋남을 줄이기 위해 사각 행동 버튼의 장식 화살표를 없애고 글자 자체를 중앙에 정렬했습니다. 방향 안내가 필요한 텍스트 링크의 화살표는 유지합니다. 적용 공정 링크는 PC·모바일 모두 기존 적갈색 강조색을 사용합니다.
- 접근과 오류: 검사 선택은 키보드로 조작하며, 상담은 오류 요약과 항목별 설명을 함께 표시합니다. 오류색과 별개로 포커스를 보이고, 팝업을 닫으면 조작하던 곳으로 돌아갑니다.
- 시연 한계: 상담은 서버·DB·메일에 전송하지 않습니다. 완료 안내 후 연락처와 동의를 초기화하며 검사 종류만 유지합니다. Figma 입력은 예시 상태 전환이고 실제 입력·검증은 웹에서 동작합니다.
- 기여 구분: 김도한이 작품 기획·디자인 방향과 Figma 수정, 피드백 선택을 담당했습니다. AI는 코드 작성·수정·검증과 일부 이미지 제작을 도왔습니다. 모든 코드를 직접 작성한 작품으로 설명하지 않습니다.
- 서체 차이: 본문은 Noto Sans KR입니다. 단계 숫자는 Figma의 JetBrains Mono와 웹의 OS 기본 모노스페이스를 사용해 글꼴 파일을 추가하지 않았으며, 기기별 숫자 모양에는 작은 차이가 있습니다.
