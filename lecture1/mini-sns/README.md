# Mini SNS

게스트·메모리 상태로 동작하는 SNS 학습 기록입니다.

[공개 사이트](https://kdhan0320-bot.github.io/dohan-portfolio/mini-sns/)

## 실행과 검사

이 작품 폴더에서 실행합니다.

```powershell
npm ci
npm run dev -- --host 127.0.0.1
npm run lint
npm run build
```

## 파일 안내

- src: 현재 화면과 동작 코드
- public: 주소로 제공되는 이미지·글꼴
- package-lock.json: 설치 버전 기록
- dist: 빌드 결과, 직접 수정하지 않음

학습 기록입니다. 게스트·mock 데이터·메모리 상태로 동작하며 현재 취업용 대표작 목록에 포함하지 않습니다.
