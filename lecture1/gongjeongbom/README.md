# 공정봄

검사 장비 모델명에 익숙하지 않은 사람이 검사 문제에서 후보 제품을 찾고, 같은 종류를 비교한 뒤 선택 이유와 공정 조건을 정리하는 인터랙션 작품입니다. 실제 사용자 조사로 검증한 서비스가 아닌 설계 실험입니다.

[공정봄 열기](https://kdhan0320-bot.github.io/dohan-portfolio/gongjeongbom/)

공통 포트폴리오 목록에 추가하지 않는 **독립 작품**으로 유지합니다. 기업·제품·사양은 가상 정보이며, 실제 이미지 분석·문의 전송·API·DB 연동은 없습니다.

## 실행

이 폴더에서 다음 명령을 실행하고 <http://127.0.0.1:4179/>를 엽니다. 별도 설치·앱 빌드 없이 HTML·CSS·JavaScript로 실행합니다. 해당 포트를 사용 중이면 다른 포트로 바꿉니다.

```powershell
python -m http.server 4179 --bind 127.0.0.1
```

## 유지할 설계와 기능

- 문제 중심 탐색: 홈의 정상·누락 샘플을 전환하고, 검사 문제나 구성 방식에서 제품을 찾습니다. 샘플 결과는 미리 정의한 예시입니다.
- 검색 복귀: 검색어·종류·문제·수준·연결 조건을 주소에 유지합니다. 관련 상세·비교·문의·완료에서 검색 결과로 돌아오며, 검색어와 필터를 각각 해제할 수 있습니다. 같은 그룹의 여러 체크 조건은 모두 충족해야 합니다.
- 제품 검토: 가상 제품 7종의 적합 조건·대안을 보여주고 같은 종류 2~3개를 비교합니다. 값이 다른 항목을 표시하고 선택 이유를 문의 요약에 연결합니다.
- 공정 초안: 사용자가 보관을 누른 경우 공정 조건·선택 제품·검토 이유 한 개를 현재 탭의 `sessionStorage`에 저장합니다. 보관·불러오기·삭제와 이탈 확인을 제공하며 저장 실패 시 작성 내용을 유지합니다.
- 개인정보 구분: 이름·회사·이메일·연락처는 초안과 복사할 요약에서 제외합니다. 자유 입력란은 내용 자체를 자동 분류하지 않으므로 개인정보 대신 공정 조건을 입력하도록 안내합니다. 초안은 삭제·데모 완료·탭 종료 시 없어지며, 브라우저 세션 복원에 따라 돌아올 수 있습니다.
- 시각 체계: 짙은 청록과 검사 영역의 모서리 프레임을 유지합니다. 연한 초록은 선택·비교 차이·보관 안내, 주황은 누락 샘플을 나타냅니다. 불필요한 화살표·아이콘·장식은 추가하지 않습니다.
- 모바일: 제품명·적합 상황·주요 행동을 도식보다 먼저 배치합니다. 보조 글자는 최소 12px, 입력은 16px이며, 메뉴·필터·이탈 안내의 키보드 닫기와 초점 복귀를 지원합니다.

## 기여와 출처

김도한이 주제·목적·화면 방향, 피드백 선택과 공개 판단을 맡았습니다. AI(Claude)는 초기 코드 작성·수정과 검증, AI(Codex)는 후속 화면·사용 흐름 개선과 브라우저 검증을 담당했습니다. 모든 코드를 직접 작성한 작품으로 설명하지 않습니다.

- Noto Sans KR: 공식 원본에서 생성한 100–900 가변 서브셋, `assets/fonts/OFL.txt` (SIL OFL 1.1). 재생성 시 공식 원본과 현재 화면 문자열·ASCII·필수 기호를 사용하며 기존 제작 도구는 `fontTools 4.63.0`과 WOFF2 지원 환경입니다.
- Roboto Mono: 모델명·기술 값용 500 굵기 서브셋, `assets/fonts/RobotoMono-OFL.txt` (SIL OFL 1.1).
- 공식 폰트 출처: [Noto Sans KR](https://github.com/notofonts/noto-cjk), [Roboto Mono](https://github.com/google/fonts/tree/main/ofl/robotomono).
- 검사 도식·브랜드 마크·`js/data.js`의 제품 구성 SVG는 프로젝트에서 제작했습니다. 실존 기업 로고·제품 사진·고객사 실적을 사용하지 않았습니다.
- 초기 Figma 제작 기록: 파일 `3ZJ4TUGqBNAewsJYzheOWo`, 화면 명세 `197:2`, 모션 `137:2`. 이후 사용자 피드백을 반영한 현재 코드·실행 화면이 최종 작업 기준이며, 초기 Figma와의 완전 일치를 주장하지 않습니다.

기준선(`../gijunseon`)과는 같은 가상 산업을 소재로 한 별개 작품입니다. 공정봄은 제품 검토 흐름, 기준선은 기업 소개를 다루며 코드·자산을 공유하지 않습니다.
