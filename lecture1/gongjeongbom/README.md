## 이번 개선의 판단 기준 — 2026-11-08

- 대상 사용자 가설: 검사 장비 모델명에 익숙하지 않은 설비·구매 검토 담당자. 실제 사용자 조사로 검증한 페르소나는 아닙니다.
- 직접 확인한 문제: 홈의 반복 안내, 버튼 이름과 도착 내용의 불일치, 비교 전 중복 설명, 모바일 상세의 큰 도식, 새로고침 시 필터 초기화.
- 설계 규칙: 홈은 문제 선택을 먼저 제공하고 제품 종류 가이드는 구성 방식으로 설명합니다. 검사 예시는 정상·누락을 직접 전환해 차이를 볼 수 있도록 했습니다.
- 탐색 규칙: 검색어·종류·문제·수준·연결 필터를 URL에 반영합니다. 같은 그룹 안의 여러 체크 조건은 모두 충족해야 합니다. 상세에서 목록으로 돌아와도 조건이 유지됩니다.
- 비교 규칙: 같은 종류 2~3개만 비교합니다. 서로 다른 값에만 배경을 표시하고, 제품 카드의 반복 설명 대신 비교표와 문의 연결에 집중합니다.
- 모바일 규칙: 제품명·적합 상황·문의 및 비교 버튼을 도식보다 먼저 배치합니다. 비교 값은 항목별로 나란히 표시합니다.
- 시각 규칙: 짙은 청록은 정보와 주요 행동, 연한 초록은 선택과 비교 차이, 주황은 검사 샘플의 누락을 나타냅니다. 실제 산업용 안전 표시의 표준을 구현한 것은 아닙니다.
- 제외한 범위: 실제 제품 성능 수치, 고객사 실적, API·DB·문의 전송. 별도 주소의 정적 데모만 공개합니다. 샘플 검사 결과는 미리 정의한 예시이며 실제 이미지 분석 기능이 아닙니다.

### 시각 판단과 범위

- 청록색과 검사 영역의 모서리 프레임을 유지하고, 01–03 검토 순서·카드의 기준선·공정 메모에 연결했습니다. 장식보다 현재 단계와 판단 기준을 먼저 구분하도록 했습니다.
- 연한 초록은 보관 안내·선택 상태·비교 차이에 사용하고, 누락 샘플의 주황색은 유지했습니다. 단계는 숫자와 문구로도 표시합니다.
- 초안은 `sessionStorage`에 명시적으로 보관합니다. 공정 조건·선택 제품·검토 이유만 포함하고 이름·회사·이메일·연락처는 제외합니다. 탭 종료, 초안 삭제, 데모 완료 시 지워집니다. 브라우저 복원 정책에 따른 세션 복원 가능성은 앱의 영구 저장 기능을 뜻하지 않습니다.
- 자유 입력란은 내용 자체를 자동 분류하지 않습니다. 개인정보 대신 공정 조건을 적도록 안내합니다. 외부 서버나 다른 사용자에게 보내는 기능은 없으며, 요약은 사용자가 눌렀을 때만 클립보드에 복사합니다.
- 초안은 한 개만 보관하며 다시 보관하면 기존 초안을 갱신합니다. 이전 공정 초안을 불러오면 공정 조건과 선택 제품을 그 내용으로 바꾼다고 먼저 안내합니다. 서버 보관·다중 초안·계정 간 공유는 제외했습니다.
- 사용자가 주제·목적 유지·개선 우선순위를 결정했고, Codex가 이번 구현·문구·시각 보완과 검수를 수행했습니다. 실제 사용자 조사나 현장 사용성 향상 수치는 확보하지 않았습니다.
