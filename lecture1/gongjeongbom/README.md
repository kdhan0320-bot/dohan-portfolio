# 공정봄

검사 제품 탐색·비교·문의 흐름 실험작입니다.

현재 GitHub Pages 배포에 포함하지 않은 실험작입니다.

## 실행과 검사

이 작품 폴더에서 정적 서버를 실행하고 http://127.0.0.1:4178/을 엽니다.

```powershell
python -m http.server 4178 --bind 127.0.0.1
```

## 파일 안내

- index.html 및 다른 HTML: 페이지 구성
- css·js: 스타일과 상호작용
- assets: 이미지·글꼴 및 출처 자료

가상 제품을 사용하는 설계 실험입니다. 실제 장비 선정이나 업체 문의 접수를 제공하지 않습니다.
