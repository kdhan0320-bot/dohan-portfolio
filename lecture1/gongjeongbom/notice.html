작품 안내

공정봄은 제조 검사 제품의 탐색·비교·문의 흐름을 다루는 인터랙션 실험작입니다. 가상 기업·데이터 범위, 폰트·그래픽 출처, 제작 기여를 이 화면에 정리합니다.

가상 기업·데모 고지

실제 장비·업체와 무관한 설계 실험입니다.

기업명·제품명·사양은 모두 화면 설계를 위한 가상 정보이며 실제 장비 선정이나 업체 문의 접수에 사용할 수 없습니다. 실존 기업 로고, 실물 제품 사진, 고객사·인증·납품 실적은 사용하지 않았습니다.

데이터 처리 범위

공정 초안은 이 탭에만, 담당자 정보는 화면에만.

담당자 정보 보관 안 함이름·회사·이메일·연락처는 초안이나 복사할 검토 요약에 포함하지 않습니다. 자유 입력란에도 개인정보 대신 공정 조건을 적어주세요.
외부 전송 안 함실제 기업·이메일·CRM으로 전달하지 않습니다.
직접 보관하는 공정 초안보관 버튼을 누르면 공정 조건·검토 이유·선택 제품만 현재 탭에 임시 저장합니다. 새로고침 후 불러올 수 있으며 탭을 닫으면 사라집니다. 초안 삭제와 데모 완료 시에도 지웁니다. 브라우저 저장 공간을 사용할 수 없으면 오류를 안내합니다.

검색어와 필터는 주소에 반영되어 상세·비교·문의와 새로고침 후에도 이어집니다. 비교 제품 ID는 현재 탭에서 유지합니다. 공정 검토 요약은 복사 버튼을 누를 때 클립보드에 복사되며, 상대방에게 자동 공유하지 않습니다.

제작 범위

김도한이 주제 선정과 화면 구성 방향, 피드백 선택과 공개 판단을 맡았습니다. AI(Claude)는 초기 코드 작성·수정과 검증을, AI(Codex)는 이번 화면·사용 흐름 개선과 브라우저 검증을 담당했습니다. 모든 코드를 직접 작성한 작품으로 설명하지 않습니다.

• 가상 사양은 산업 장비 성능이나 현장 적합성을 보증하지 않습니다.

검증하지 못한 범위

• 실제 screen reader 음성 출력은 별도 검증이 필요합니다.

• 운영 환경 Core Web Vitals, 법적 권리 체인 전체는 이 저장소만으로 확인할 수 없습니다.
