상위 `AGENTS.md`를 따르되, 아래의 최신 사용자 사전 승인을 이 프로젝트에 적용한다.

## 2026-11-05 사용자 승인

- 사용자 지시: “우선 커밋 배포,백업부탁해. 앞으로 수정되면 커밋배포 해줘. 그다음 내가 직접확인할게”
- `projects/my-portfolio`에서 사용자가 요청한 수정은 필요한 검수 후 commit·push·기존 GitHub Pages 배포까지 진행한다. 동일 범위의 작업마다 배포 승인을 다시 요청하지 않는다.
- 현재 배포 주소는 `https://kdhan0320-bot.github.io/dohan-portfolio/my-portfolio/`이다. 다른 호스팅으로의 이전이나 공개 대상 변경까지 승인한 것은 아니다.
- 배포 직전 버전과 검증된 새 버전을 복구 가능한 GitHub 백업 브랜치로 보존한다. 이 백업용 브랜치 생성은 위 백업 요청 범위에 포함된다. 기존 백업을 덮어쓰거나 삭제하지 않는다.
- 최신 원격 저장소의 다른 프로젝트 변경과 로컬의 관련 없는 작업을 보존한다. main 반영 시 예상 HEAD를 확인하고 강제 덮어쓰기를 하지 않는다.
- package·lockfile·workflow·DB·migration·Secrets·계정·비용 및 삭제·이동·rename은 기존 별도 승인 규칙을 유지한다.
- 완료 시 공개 주소, 배포 결과, 백업 위치, 검증 범위 및 남은 제한을 간단히 보고한다.
