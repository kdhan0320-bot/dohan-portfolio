기준선 구현 노트

산업용 비전 검사를 소개하는 가상 기업 사이트입니다. 기존 Figma 작품을 실제 HTML 요소와 반응형 웹으로 구현했습니다.

실행 화면 보기 ↗ Figma 원본 새 창↗ 모바일 프로토타입 새 창↗ 코드·실행 방법 새 창↗
목표
디자인 구현 · 반응형 · 기본 상호작용
범위
메인 · 적용 공정 · 검사 3종 · 도입 절차 · 상담
기반
HTML · CSS · JavaScript
패키지 설치·빌드 없이 실행

제작 역할

본인 — 원본 Figma 작품과 요구 범위를 제시하고, 디자인 방향과 수정 결과를 확인했습니다.

AI 지원 — 코드 작성, 반응형·접근성 보완, 도식 정리와 검수를 지원했습니다. 이 결과물만으로 본인의 독립적인 코딩 능력을 검증했다고 주장하지 않습니다.

핵심 구현 3가지

  1. 01

    반응형과 사진 구성

    Grid·Flex로 화면 폭에 맞춰 배치와 메뉴를 바꿉니다. 사진 크기별 파일을 제공하고, 검사 표시와 확대 위치는 비율로 관리합니다.

    css/home.css · js/images.js

  2. 02

    이어지는 검사 선택

    탭·사진·설명·상담 항목이 같은 검사 데이터를 사용합니다. URL에 선택을 반영해 직접 진입과 뒤로가기도 지원합니다.

    js/data.js · js/inspection.js

  3. 03

    키보드와 폼 안내

    탭 방향키, 보이는 초점, 안내창의 Escape·초점 복귀를 제공합니다. 폼 오류는 해당 입력칸으로 연결하고 검사 변경·개인정보 안내 중에도 입력을 유지합니다.

    js/common.js · js/consultation.js

시연과 검증 범위

문의는 브라우저 안에서만 확인하는 시연입니다. 서버 전송·개인정보 저장·실제 상담 접수는 하지 않습니다.

마감 검증 · 2026-10-21
선생님 피드백이 반영된 Figma에 맞춰 메인 상담·푸터, PC 검사 설명, 도입 단계 배치와 상담 사진 선택을 수정했습니다. 주요 7화면을 320·390·768·1440px에서 확인하고 공정·상담은 1920·2552px에서도 확인했습니다. 네 폭에서 상담 오류·키보드 이동·완료 후 초기화를 검사했으며 메뉴·검사 선택·팝업·도입 단계 이동도 직접 확인했습니다. 상세 범위는 코드·실행 방법의 기록에서 확인할 수 있습니다.

긴 오류 문장의 불릿을 첫 줄에 맞추고, 축소된 검사 표시선의 두께를 보완했습니다. 오류 표시와 키보드 초점은 함께 보입니다. 검사 변경·개인정보 안내를 닫을 때는 입력을 유지하고, 시연 완료 안내를 닫으면 연락처·동의·오류를 초기화한 뒤 회사명으로 초점을 옮깁니다. 선택한 검사 종류는 유지합니다.

실제 휴대전화·Safari·Firefox·스크린리더·외부망 로딩 속도는 미검증입니다. 실제 검사 정확도·인증·고객 실적을 주장하지 않습니다.
