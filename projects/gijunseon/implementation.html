기준선 구현 노트

산업용 비전 검사를 소개하는 가상 기업 사이트입니다. Figma 디자인을 바탕으로 홈의 제품 소개와 검사 예시, 별도 도입 절차, 상담 시연을 반응형 웹으로 구성합니다.

구현 방식

  1. 01

    디자인을 문서 구조로

    제목·탭·폼을 실제 HTML로 나누고 공통 색상은 CSS 변수로 관리했습니다. 검사 표시는 원본 628×471 좌표를 비율로 변환해 사진이 줄어도 같은 부위를 가리킵니다.

    css/style.css · js/inspection.js

  2. 02

    콘텐츠에 맞춘 반응형

    Grid/Flex로 배치를 조정했습니다. 메뉴는 900px 이하에서, 검사 사진은 700px 이하에서 구성을 바꾸며, 모바일 배너는 제목과 사진을 나눠 읽기 쉽게 배치했습니다.

    css/home.css · css/inspection.css

  3. 03

    선택을 다음 화면까지

    검사 데이터와 URL의 type을 연결해 탭·사진·설명·상담 항목을 맞췄습니다. 직접 진입과 뒤로가기를 지원하고, 탭은 방향키·Home·End로 조작합니다.

    js/data.js · js/inspection.js

  4. 04

    오류 안내와 초점 이동

    빈 값·이메일 형식·필수 동의를 확인하고, 오류 요약에서 입력칸으로 이동합니다. 안내창은 Escape로 닫고 원래 위치로 초점을 돌려줍니다.

    js/consultation.js · js/common.js

피드백을 반영한 보완

  • 페이지 역할홈에는 제품 소개·검사 3종·도입 검토 요약을 둡니다. 적용 공정은 검사 시점을, 별도 도입 절차는 검토 흐름을 설명하고 상담 시연으로 연결합니다.
  • 검사 설명사진 아래에 검사 대상·확인 포인트·상담 전 준비를 추가했습니다. 인쇄 예시와 실제 바코드 판독 결과도 구분했습니다.
  • 입력 유지상담 중 준비 안내를 읽고 돌아올 때 페이지를 다시 열지 않아, 입력 내용과 선택 검사를 유지합니다.
  • 브랜드와 제목기존 색상을 유지하고 두 로고 후보 중 선택한 심볼 정돈안을 적용했습니다. 로고의 선·간격과 제목의 굵기를 정돈하고, 파비콘은 작은 크기용 완전한 형태로 보완했습니다.
  • 도식과 모바일도입 과정과 공정 안내의 카메라·대상물·선 굵기를 같은 SVG 표현으로 맞췄습니다. 모바일에서는 도식 옆에 설명을 배치하고 사진과 여백을 조절했습니다.
  • 포커스와 안내어두운 영역의 키보드 초점은 밝은 강조색과 짙은 받침으로 구분합니다. 시연 확인 문구를 명확히 하고, JavaScript가 없을 때 작동하지 않는 안내 버튼은 비활성화했습니다.
  • 이미지 전달Figma 원본은 보존하고, 큰 사진에는 크기별 WebP를 적용했습니다. 검사 선택 후 필요한 이미지만 요청하며 전체·확대 사진은 같은 파일을 공유합니다. 이미지 최적화 회차에서 인쇄 검사 초기 리소스는 6.08MB에서 0.464MB로 약 92.4% 줄었습니다. 이번 마감 이후 용량을 재측정한 수치는 아닙니다.

제작 범위와 AI 활용

기존 Figma 작품을 바탕으로 코드 작성·반응형·접근성 보완과 검수에 AI 코딩 지원을 활용했습니다. 이 문서는 실제 구현 방식과 실행한 검사 결과를 기록합니다.

검증과 시연 범위

홈·도입 절차 확장 검증 · 2026-10-18 · 로컬 Chromium · 320·390·768·1440px

홈과 새 도입 절차를 렌더링하고 실제 캡처를 확인했습니다. 검사 범위에서 가로 넘침·누락 이미지·페이지/콘솔/HTTP 오류를 발견하지 못했습니다. 도입 절차는 배치 전환 부근 760·761px에서도 확인했습니다.

22개 핵심 동작 검사가 통과했습니다. 메뉴·탭·뒤로가기·필수 입력 오류·안내창의 키보드 조작과 초점 복귀, 상담 준비 이후 입력·동의·검사 선택 유지와 개인정보 비전송을 재검사했습니다. 새 도입 절차의 단계 이동과 상담 연결도 확인했습니다.

앞선 이미지 최적화 비교는 같은 390×844px·DPR 1·빈 캐시·스크롤 전 조건에서 문서를 제외한 리소스 본문 용량을 측정한 결과입니다. 이번 확장본의 용량을 다시 측정한 수치는 아닙니다.

실제 휴대전화, Safari·Firefox, 스크린리더와 외부 배포 환경의 로딩 속도는 미검증입니다.

문의는 브라우저 안에서만 검증하며 서버로 전송하거나 개인정보를 저장하지 않습니다. 실제 상담 접수·API·DB 기능은 없습니다.

선택한 A 로고를 유지한 홈 제품 소개·별도 도입 절차 확장본입니다. 미리보기 확인과 배포 승인을 거쳤으며, 위 검증 기록은 로컬 Chromium에서 확인한 범위를 설명합니다.
