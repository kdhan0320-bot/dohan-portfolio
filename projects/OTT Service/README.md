# 잔상관 · JANSANG CINEMA

가상 단편 영화 6편을 발견하고, 찜하고, 개인 영화 노트를 남기는 반응형 영화 탐색 웹입니다. HTML/CSS/Vanilla JavaScript로 만든 포트폴리오 콘셉트이며 실제 영상·상영·예매 서비스는 아닙니다.

## 2026-10-06 탐색과 보관함 마감 (v12)

모바일의 대표 영화 제목과 인물 이미지가 겹치고, 노트만 남긴 영화를 다시 찾기 어려웠던 부분을 수정했습니다. 메뉴 수를 늘리기보다 영화 발견 → 상세 → 찜·노트 → 내 보관함 흐름을 명확히 했습니다.

- 모바일 대표 장면과 제목을 위아래로 분리하고 높이·여백을 조정. 로고 자간을 완화하고 작은 작품 정보·라벨을 보강. 대표 영화의 찜 완료는 테두리 상태로 구분해 영화 살펴보기 버튼이 먼저 보이도록 정리.
- 섹션 제목은 밝은 중립색, 라임은 짧은 범주 라벨·주요 행동·선택 상태에 사용. 홈의 필름 배경을 약하게 유지해 포스터와 경쟁하지 않도록 조정.
- 인물 포스터 6종은 유지. 홈 기획전 두 곳만 기존 생성 스틸인 편지 장면·관측기지로 바꾸고 선정 이유를 한 줄씩 표시. 외부 영화 이미지·새 글꼴·패키지를 프로젝트에 추가하지 않음.
- `나의 찜`을 `내 보관함`으로 변경. 찜 또는 노트가 있는 작품을 중복 없이 모아 `전체 / 찜한 영화 / 노트 있는 영화`로 구분. 카드에 `노트 있음` 배지 표시.
- 보관함은 세 분류와 검색만 표시. 분위기 필터는 영화 메뉴에 유지하며 보관함 진입 시 숨은 분위기 조건이 남지 않도록 초기화.
- `나의 감상 노트`를 `나의 영화 노트`로 정리. 찜하지 않은 영화도 노트 저장 즉시 보관함에 나타나며, 찜을 해제해도 노트가 있으면 남음. 마지막 노트를 삭제한 뒤에는 빈 상태와 초점을 갱신.
- 기존 저장 키·작품 ID는 유지. 다른 탭에서 현재 영화의 노트가 바뀌었을 때만 충돌 안내를 표시하며, 작성 중인 내용은 보존.

현재 Chromium의 로컬 소스 검증 결과입니다. 실제 iOS/Safari/Firefox·스크린리더·사용자 과제 실험은 수행하지 않았습니다. 계정·공개 게시판·영상 재생·예매·결제는 구현 범위 밖이며, 노트는 해당 브라우저에만 저장됩니다. 커밋·배포 성공 여부는 이 로컬 검증 결과와 별도로 확인합니다.

## 2026-09-28 타이틀 위계와 영화 탐색 마감 (v11)

v10은 대비·잘림을 보정했지만 로고·대표 영화·포스터의 비슷한 명조와 회백색 표현이 반복되었습니다. 영화 콘텐츠의 개성과 탐색 UI를 분리하도록 수정했습니다. 이는 디자인 판단이며 실제 관객 조사나 채용 성과의 증명은 아닙니다.

- 브랜드는 굵은 Pretendard 워드마크, 대표 영화는 대형 고딕과 두 색으로 구분. 명조를 모든 대표 요소에 반복하지 않음.
- 6개 영화 타이틀은 기존 두 글꼴 안에서 서체·굵기·자간·행 비율을 다르게 구성. 드라마의 따뜻한 크림/살구, SF의 냉색, 미스터리와 다큐의 연녹색을 작품에 한정해 사용.
- 공통 UI는 차콜 `#0B0E12`, 본문 `#F6F5F0`, 주요 행동·선택 상태 `#D9EC8E`. 메타정보는 중립색으로 정리. 심벌·파비콘 색도 함께 수정.
- 대표 작품 → 선별 영화4편 → 기획전3개 → 대표 매거진1편 흐름. 5개 메뉴와 전체 영화6편을 유지. 첫 화면의 반복 슬로건을 실제 영화 목록 링크로 교체.
- 섹션 제목은 짧은 범주 라벨과 굵은 고딕으로 구분. 긴 영화명·매거진 제목·기획전 설명은 의미 단위로 줄 구성. 모바일 기획전 화살표는 카드 오른쪽 안쪽선에 정렬.
- 태블릿 매거진은 가로형 이미지와 본문, 280px 최소 높이로 구성해 원본 포스터 비율 때문에 생기던 약400px 높이의 과한 빈 공간 해소.
- 누적된 CSS 재정리. 저장 키·작품ID·노트 저장 로직은 유지. JavaScript 변경은 표시용 제목·설명과 상세창의 작품 색상 연결에 한정.
- 새 외부 이미지/글꼴/패키지는 추가하지 않음. 기존 생성 이미지, 자체 SVG, Pretendard/Noto 기반 OFL 글꼴과 출처 기록 유지.

## 이전 제목 가독성과 선택 흐름 마감 (v10)

v9의 대비·넘침 검사만으로 제목의 위계와 읽기 편한 정도까지 충분히 판단할 수는 없었습니다. 작은6열 포스터, 약한 제목 굵기, 모바일에서 한 단어만 남는 마지막 줄을 이번 수정의 대상으로 삼았습니다.

- 홈은 대표4편을4열(1000px 이상)/2열로 확대. 대표 장면·기획전과 중복되는 두 작품은 홈 목록에서 덜어내고, 영화 메뉴는 전체6편을 계속 제공.
- 영화 목록은768px 이상3열, 그 아래2열. 홈과 전체 목록의 역할을 나누면서 작품 이미지와 제목을 키움.
- 영화 제목은 기본34px, 좁은 데스크톱/태블릿27–28px, 모바일24px(359px 미만21px). 굵기700을 중심으로 보강하고 SF 제목만650으로 구분.
- 긴 영화명은 `파도가 / 머문 자리`, `불이 / 켜지는 시간`으로 의미 단위 줄을 지정. 접근 가능한 버튼 이름에는 원래 전체 제목 유지.
- 어두운 포스터 오버레이를 하단50%로 줄여 인물·의상·장면을 더 드러냄. 제목 뒤의 어두운 바탕은 유지하고 재측정.
- 모바일 장르·러닝타임은 의도한2줄로 통일. 제어·검색·상세와 보조 정보의 크기·색을 보강.
- 기획전 상단의 중복 제목/설명 축소. `기획전→테마 선택→짧은 설명·총시간→작품` 순서. 다른 영화 링크는 작품 아래에 배치.
- 매거진 제목을 의미 단위2줄로 구성.601–999px에서는 가로형 이미지+본문 목록,1000px 이상3열,600px 이하세로형1열로 표시.
- 기존 자체 생성 이미지·SVG와 로컬 OFL 글꼴 재사용. 이번에는 새 외부 자산을 가져오지 않음. 출처와 라이선스 원문 보존.

홈 선별과 표시 제목을 제외한 찜·개인 노트 저장 로직과 키는 유지했습니다. 기존 기록의 형식·유효 작품 ID는 바꾸지 않았습니다. 이는 디자인 판단과 화면 검증이며 채용 성과나 실제 사용자 과제 성공률의 증명은 아닙니다.

## 이전 로고·타이포그래피·배경 마감 (v9)

현재 배포 코드에서 데스크톱 메뉴는 최소 클릭 폭의 왼쪽에 글자가 놓이고 밑줄은 전체 폭을 차지했습니다. 이전 필름 배경도 참조되지 않았습니다. 확인된 문제와 실제 화면 검토를 바탕으로 다음을 보정했습니다.

- 화면 비율의 가로 프레임과 세 겹 잔상을 조합한 자체 SVG 심벌. 헤더·푸터·파비콘을 동일하게 적용.
- 브랜드·대표작·일부 포스터는 Noto Serif KR에서 만든 600–700 제목용 서브셋, 메뉴·본문·제어는 Pretendard. 전체 제목을 같은 굵은 고딕으로 처리하던 단조로움을 줄임.
- 메뉴는 클릭 영역과 글자 묶음을 중앙 정렬하고 선택 표시를 24px로 통일. 모바일의 읽을 수 없을 만큼 작은 브랜드 영문은 표시하지 않음.
- 반복되는 영문 섹션 제목·포스터 소제목·테마 라벨을 덜어냄. 홈은 대표작→영화→기획전→매거진 순서와 실제 다섯 메뉴를 유지.
- 기존 자체 생성 필름 배경을 홈과 내부 화면에 복원. 작은 글자와 탭에는 어두운 바탕을 두어 이미지 위 대비 확보.
- 본문은 중성에 가까운 회백색, 보조 정보는 중성 회색, 선택·행동은 연한 청색으로 구분.
- 가로 기획전 배너의 얼굴 크롭과 태블릿 기획전 카드의 오른쪽 정렬을 수정.

## 포트폴리오와 Figma 정리 기준

취업용 표현은 **‘영화 탐색·개인 기록 UI / 반응형 웹 퍼블리싱’**이 적절합니다. 사용자 연구·매출·전환율·상용 OTT 운영 성과를 주장하지 않습니다. 이미지는 AI 활용임을 밝히고, 본인의 정보 구조·레이아웃·상태·반응형 구현과 검증을 구체적으로 설명합니다.

별도 Figma 정리 시 기존 프로젝트의 순서 `00 COVER / 01 SYSTEM / 02 READY 모바일 / 03 READY 반응형 / 04 MOTION / 05 SPEC_QA / 90 ARCHIVE`를 유지할 수 있습니다. READY에는 홈→영화 또는 기획전/매거진→상세→찜/노트의 화면을 놓고 빈 결과·빈 찜·저장 오류는 해당 화면 아래에 붙입니다. 긴 리서치 문서나 모든 화면을 잇는 복잡한 선 대신 두 핵심 과제(영화 찾기, 기록 남기기)를 나눠 보여줍니다. 이는 정리 기준이며 이번에 Figma를 수정한 것은 아닙니다.
