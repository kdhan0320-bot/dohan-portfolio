# 잔상관 · JANSANG CINEMA

가상 단편 영화 12편을 소개하고, 관심 작품을 찜하고, 개인 영화 노트를 남기는 반응형 영화 발견 웹입니다. HTML/CSS/Vanilla JavaScript로 만든 포트폴리오 콘셉트입니다. 실제 개봉작의 흥행 정보와 외부 OTT 혜택은 출처·기준일을 표시한 별도 영역에서 안내합니다. 영상 제공·극장 예매 서비스는 아닙니다.

## 2026-10-06 영화 발견 서비스 개편 (v13)

- 로고를 홈 진입점으로 두고 **영화 / 기획전 / 매거진 / 소식·혜택 / 내 보관함** 다섯 메뉴로 구분했습니다.
- 기존 가상 작품 6편에 애니메이션·음악·미스터리·스포츠·드라마 6편을 더했습니다. 기존 작품 ID와 찜·노트 저장 키는 유지합니다.
- 인물과 사건을 읽을 수 있는 실사풍·애니메이션 포스터를 함께 사용합니다. 신규 포스터 6장, `파란 오후` 대표 장면 1장, 자체 기획전 배너 1장을 생성했습니다.
- 홈의 12편 포스터 목록은 이전·다음 화살표와 가로 스크롤을 제공하고, 전체 영화에는 추천순·짧은 러닝타임순·제목순 정렬을 추가했습니다.
- 찜은 북마크 아이콘으로 통일했습니다. 작품별 접근 가능한 이름과 선택 상태를 함께 제공하며, 노트가 있는 작품은 별도 표시합니다.
- 기획전 3개에 각 4편, 매거진 4편을 연결했습니다. 소식·혜택에는 실제 KOBIS 집계, 공식 OTT 혜택, 자체 큐레이션 캠페인을 구분해 배치합니다.
- 짙은 청색 바탕과 밝은 시안색 액션, 살구색 캠페인으로 공통 UI를 정리하고 작품마다 색·인물·제목 구성을 달리합니다.

### 실제 검증 (v13)

- Chromium 153에서 23개 기능군 통과: 12작품 상세, 신규 6편의 찜·노트 CRUD, 검색·분위기·정렬 조합, 보관함 합집합·분류, 실제 교차 탭 동기화·충돌 보존, 손상 데이터·저장 차단·쓰기 실패, 모달·초점 복귀·뒤로가기·동작 줄이기.
- 가로 목록은 390/1440px에서 화살표·네이티브 스크롤·수동 휠·좌우키·Home/End·양끝 비활성·마지막 카드 초점 복귀를 확인. 휠 관성 및 다음 프레임의 상태 갱신을 기다리도록 검사 타이밍을 보정한 뒤 해당 그룹을 재검증했습니다.
- 320 / 390 / 600 / 767 / 768 / 999 / 1440px × 홈·영화·기획전 개요/상세 3곳·매거진·소식·보관함 9경로, 총 63개 배치 확인. 의도된 포스터 가로 목록 이외의 화면 넘침·이미지 실패·JS 오류 없음. 주요 제어는 44px 이상.
- 실제 PNG 검토로 매거진 대표 이미지의 과도한 높이, 모바일 상단 포스터 제목 겹침, 배너 문구 대비, 기획전 인물 크롭, 메뉴 밑줄과 글자의 겹침을 수정했습니다. 추가로 320/359/390/600/601px의 60개 포스터에서 제목과 북마크의 충돌·제목 영역 이탈 0건을 확인했습니다.
- 320/390/1440px의 5경로에서 실제 배경 픽셀을 포함한 텍스트 621개 표본 검사. 크기별 대비 기준 미달 0개, 일반 텍스트 최소 4.73:1·큰 제목 최소 3.27:1. 전수 접근성 인증이 아닌 표본 검사입니다.
- 홈·소식의 내부 목적지 9개와 공식 외부 링크 3개의 주소·새 창 속성 확인. 외부 서비스의 실제 가입·결제는 수행하지 않았습니다.

검사는 저장소 밖 일회성 Playwright 스크립트로 수행했습니다. 실제 iOS/Safari/Firefox·스크린리더 낭독·사용자 과제 실험은 수행하지 않았습니다. 아래 v12 검증은 이전 버전의 이력이며 v13 결과로 재사용하지 않습니다. 배포 성공은 GitHub Actions 및 공개 파일 응답으로 별도 확인합니다.

기획전 직접 주소는 `#themes/quiet`, `#themes/warmth`, `#themes/beyond`입니다. 경로 변경은 브라우저 뒤로가기와 연결합니다. 영화·매거진 상세는 경로와 별도의 dialog이며 닫으면 기존 화면으로 돌아갑니다.

핵심 과제는 **영화 찾기 → 소개 읽기 → 찜**, **관심 영화 → 개인 노트 → 내 보관함에서 다시 찾기**입니다. 실제 흥행 정보나 구독 조건을 확인하는 행동은 소식·혜택에서 공식 서비스로 연결합니다.

## 구현 범위와 저장 방식

- 제목·영문·장르·분위기·키워드 검색, 조건 초기화와 빈 결과를 제공합니다.
- 가상 영화 12편 상세, 기획전 3개, 매거진 4편과 관련 작품을 연결합니다.
- 포스터 캐러셀의 양 끝 상태, 북마크 상태, 정렬·검색·분위기·보관함 분류를 UI에 표시합니다.
- Native dialog를 사용합니다. Escape·배경 클릭·닫기, 포커스 순환·복귀, 경로 이동 시 닫기 처리를 포함합니다.
- 찜 키는 `jansang-cinema:saved:v1`, 노트 키는 `jansang-cinema:notes:v1`입니다. 기존 6편의 ID를 유지합니다.
- 작품별 개인 노트는 최대 280자입니다. 빈값 검증, 저장·수정·삭제, 입력 중 안내, 사용자 텍스트의 HTML 실행 방지 처리를 포함합니다.
- 로컬 저장의 새로고침 유지, 다른 탭 변경 동기화, 손상 데이터 처리, 저장 불가 시 페이지 메모리 대체, 작성 중 충돌 안내를 포함합니다.

노트는 해당 기기·브라우저에만 저장되며 브라우저 데이터를 지우면 사라집니다. 회원가입·로그인·공개 게시물·영상 재생·예매·결제·개인화 API·서버 DB는 구현 범위에 없습니다. 개인 노트와 공개 게시물 기능을 같은 것으로 설명하지 않습니다.

잔상관은 인물·사건이 있는 영화 포스터와 장르별 색차, 와이드 장면을 중심으로 다른 프로젝트와 구분합니다. 차분한 청색 UI는 사용자가 요청한 이미지 방향을 반영한 디자인 선택입니다. 성격·퍼스널컬러를 검증한 결과나 채용 성과의 증거로 제시하지 않습니다.

- `index.html`: 홈과 다섯 메뉴 화면, 자체 SVG 심벌, 영화·매거진·안내 dialog, 실제 정보의 기준일·외부 링크.
- `css/style.css`: 반응형 레이아웃, 포스터 제목과 크롭, 입력·선택·포커스 상태.
- `js/main.js`: 가상 작품·기획전·기사, 경로·검색·정렬·캐러셀·찜·노트·저장 처리.
- `assets/posters-v8/`: 기존 작품 포스터 6장 및 이전 대표 이미지 보존.
- `assets/posters-v13/`: 신규 작품 포스터 6장과 `bluehour-hero.webp`.
- `assets/campaigns-v13/film-weekend.webp`: 자체 기획전 배너.
- `assets/ASSET_PROVENANCE.md`: 신규 이미지 8장의 전체 생성 프롬프트·치수·해시·처리 기록, 기존 자산과 글꼴 라이선스.

외부 영화 이미지·상용 포스터·배우 사진·브랜드 로고를 새로 가져오지 않았습니다. 생성 이미지 사용과 출처 기록은 법적 무위험이나 독점권을 보증하지 않습니다. 이전 자산·글꼴 파일 및 라이선스 고지는 보존합니다.

별도 빌드 없이 로컬 HTTP 서버로 실행합니다. 배포 경로 `/ott-service/`와 저장소 폴더명은 유지합니다. 현재 기준 소스는 이 HTML/CSS/JavaScript이며 별도 Figma 파일은 이번 수정 대상이 아닙니다.

## 포트폴리오와 Figma 정리 기준

취업용 설명은 **영화 발견·개인 기록 UI / 반응형 웹 퍼블리싱**입니다. 가상 작품과 AI 이미지 활용 범위, 본인의 정보 구조·시각 체계·상태·반응형 구현, 실제 수행한 검증을 구분합니다. 사용자 연구·전환율·매출·상용 OTT 운영 성과를 주장하지 않습니다.

별도 Figma 정리 시 `00 COVER / 01 SYSTEM / 02 READY 모바일 / 03 READY 반응형 / 04 MOTION / 05 SPEC_QA / 90 ARCHIVE`를 사용할 수 있습니다. 영화 찾기와 기록 남기기 두 과제로 화면을 묶고, 빈 결과·빈 보관함·저장 오류는 해당 화면 아래에 붙입니다. 긴 설명과 전체 화면을 잇는 복잡한 선 대신 각 선택의 다음 화면을 보여주는 정리 기준입니다. 이번 작업에서 Figma를 수정했다는 의미는 아닙니다.

## 이전 검증 이력 — v12 (2026-10-06)

다음은 **6편·3개 기사였던 v12의 검증 기록**입니다. v13의 12편·새 메뉴·캐러셀·정렬·이미지·배너는 이 결과에 포함되지 않으며 별도 재검증이 필요합니다. v8–v11의 상세 변경과 검증 이력은 Git 이력에 보존됩니다.

- Chromium 153에서 18개 기능군 통과: 6작품·3기획전·3기사, 검색·분위기·보관함 분류, 노트 CRUD·찜 합집합·새로고침, 실제 두 탭의 변경·삭제·입력 충돌, 손상 JSON·저장 차단·쓰기 오류, 280자·HTML 형태 입력, 모달·키보드·초점 복귀·뒤로가기·동작 줄이기.
