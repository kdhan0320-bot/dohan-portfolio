분위기와 러닝타임으로 가상 단편영화 12편을 발견하고, 관심 작품과 메모를 모아두는 반응형 큐레이션 웹입니다. 핵심 흐름은 **영화 찾기 → 작품 살펴보기 → 찜하기 → 내 보관함에서 다시 찾기**입니다. HTML/CSS/Vanilla JavaScript로 만든 포트폴리오 프로토타입이며 실제 영상 재생·예매·결제는 제공하지 않습니다.

## 2026-10-11 장면 중심 시각 구성·조작부 마감 (v21)

- 메인을 큰 가로 장면과 짧은 문구가 한 화면을 이루는 구도로 변경했습니다. 모바일은 이미지를 먼저 보여주고 목적 문장과 단편영화 찾기 버튼을 연결합니다. 대표 작품 정보·작품 보기 행동은 장면 아래 한 행으로 제공합니다.
- 홈 큐레이션은 숲·바다·파란 오후의 가로 스틸 조합과 짧은 세이지색 설명 띠를 사용합니다. 큐레이션 목록·상세는 숲·편지·우주 전용 가로 스틸을 사용하여 세로 포스터 확대에 따른 인물 잘림을 없앴습니다. 큐레이션 노트 이미지도 해당 작품의 기존 가로 스틸로 연결합니다.
- 잔상 프레임은 큰 장면의 상단·오른쪽 바깥에만 반복해 글 영역을 가로지르지 않도록 했습니다. 빈 보관함에는 프레임과 북마크를 조합했습니다. 새 이미지 생성이나 외부 자산 추가 없이 기존 자산을 재사용합니다.
- 홈 영화 목록의 화살표를 포스터 밖 하단으로 옮겨 **이전 · 현재 범위 · 다음** 한 행으로 묶었습니다. 끝의 비활성 버튼도 자리를 유지하고, 모든 영화가 보이면 조작부 전체를 숨깁니다. 44px 조작 영역과 키보드 이동은 유지합니다.
- 홈 포스터 아래 중복 작품명은 생략하고 장르·시간·찜을 한 행으로 정리했습니다. 검색·큐레이션 상세·보관함은 비교하기 위한 고정 작품명을 유지합니다. 북마크의 실제 모양을 키우고 메모 펼치기 선 굵기를 맞췄습니다.
- 기존 작품 ID, 찜·메모 저장 형식, 검색·필터·정렬·동기화는 유지합니다. 일반 웹 글씨는 기존 400–450 중심 굵기를 유지하고 포스터 표현은 보존했습니다.

## 이전 이력: 2026-10-11 시선 흐름·보관함 상태 마감 (v20)

- 내 보관함의 원형 숫자 배지를 없앴습니다. 0편이면 숫자를 숨기고, 저장한 작품이 있을 때만 글자와 나란히 수량을 표시합니다. 보관함 수는 찜 또는 메모가 있는 작품의 합집합입니다.
- 첫 화면의 중복 보관함 링크와 비어 있는 홈 보관함 안내를 제거했습니다. 홈 보관함은 실제 보관 작품이 있을 때만 나타납니다. 첫 화면 문구는 작품 탐색과 찜의 행동을 짧게 설명합니다.
- 보관함 전체가 비면 검색·분류·결과 수를 숨기고 영화 찾기 버튼을 제공합니다. 검색 결과나 일부 분류만 0편인 경우에는 조건을 바꿀 수 있도록 도구를 유지합니다. 다른 탭에서 마지막 작품을 제거해 초점이 있던 영역이 사라지는 경우에도 보이는 행동으로 초점을 옮깁니다.
- 홈·영화 찾기·큐레이션 상세·보관함의 공통 카드에서 찜 버튼을 포스터 아래 작품 정보 옆으로 이동했습니다. 조작 영역은 44px을 유지하고, 작품명·장르·러닝타임을 일정한 위치에 배치합니다. 포스터 자체의 타이포그래피는 유지합니다.
- 홈의 대표 큐레이션 이름을 목록·상세와 같은 ‘파란 숨 고르기’로 맞추고 선정 기준 한 문장을 제공합니다. 제목의 강제 줄바꿈을 제거하고 히어로 설명은 의미 단위로 줄을 나눴습니다.
- 점·곡선 배경을 제거하고 겹친 프레임과 약한 빛으로 장식 원칙을 정리했습니다. 차콜 바탕과 기존 큐레이션 색상, 가벼운 웹 글씨 굵기를 유지했습니다.

## 이전 이력: 2026-10-11 전체 화면 여백·아이콘 마감 (v19)

- 320px에서 홈 제목이 390px보다 커지던 예외 규칙을 수정했습니다. 좁은 화면의 제목·섹션 제목·분위기 필터 패딩을 일관된 크기로 맞췄습니다.
- 모바일/태블릿 홈의 작품 수와 러닝타임 선택을 같은 행에 배치했습니다. 레이블은 보조기술에 제공하며, 분위기 선택과 포스터 사이의 불필요한 세로 공간을 줄였습니다.
- 홈의 구간 제목·보조 링크는 공통 중앙 정렬과 44px 행을 사용합니다. 모바일 큐레이션 텍스트 패널의 패딩·간격을 줄여 이미지가 더 빨리 나타나게 했습니다.
- 단독 조작 아이콘은 20px, 글자 결합·검색 내부 아이콘은 18px을 기준으로 정리했습니다. 조작 영역의 44px 이상 크기는 유지합니다.
- 상세 줄거리의 행간·상하 간격을 조정하고, 메모 입력부의 중복 제목을 접근성용 레이블로 남겼습니다. 저장 위치 안내와 글자 수는 한 행으로 묶었습니다.
- CSS·JavaScript 참조 주소의 버전을 현재 파일의 SHA-256 앞 12자리로 갱신했습니다. 다음 변경에서도 수정한 자산의 버전 주소를 갱신해야 합니다.

## 이전 이력: 2026-10-11 목적 전달·행 배열·시각 마감 (v18)

- 첫 문구를 **‘단편영화를 고르고, 취향을 모으세요.’**로 바꿨습니다. 영화 찾기와 북마크 아이콘이 있는 내 보관함을 한 행동 묶음으로 배치합니다.
- 포스터 외 웹 제목은 주로 430–450 굵기로 낮추고 자간을 -0.025em 안팎으로 완화했습니다. 히어로 행간은 1.4 이상으로 설정했습니다. 본문은 400, 로고는 550을 사용합니다. 포스터 전용 서체·굵기는 보존했습니다.
- 분위기 필터를 전체/잔잔함/따뜻함/긴장감/상상력으로 정리했습니다. 모바일은 5열 한 행으로 고정하여 선택지 하나만 다음 줄로 떨어지는 문제를 없앴습니다. 필터의 과도한 외곽선을 줄이고 선택 상태로 강조합니다.
- 홈 큐레이션 제목의 위계를 다른 구간과 맞추고 중복 설명을 줄였습니다. 숲·바다·새벽 식탁의 기존 장면을 조합해 한 작품이 아닌 여러 작품의 컬렉션을 표현합니다. 태블릿 히어로 이미지 크롭과 모바일 제목 띄어쓰기를 보완했습니다.
- 텍스트 결합 북마크는 18px 정사각형, 간격 8px, 행간 1.5로 맞췄습니다. 검색·결과 초기화 아이콘도 정사각형으로 통일했습니다. 푸터 링크는 모바일에서도 수평 배치합니다.
- 콘텐츠 바깥쪽에 낮은 대비 점 패턴, 히어로 주변에 정적인 곡선과 빛을 적용했습니다. 장식은 포인터 입력을 받지 않습니다. 작품이 모두 보이는 레일은 중복 범위 표기와 불필요한 여백을 숨깁니다.

- 찜은 북마크 버튼과 선택 상태로 표시합니다. 작품 상세에는 ‘찜하기 / 찜한 영화’ 텍스트를 함께 표시합니다. 저장한 메모가 있는 작품은 별도 배지를 표시합니다.

- 찜 키는 `jansang-cinema:saved:v1`, 메모 키는 `jansang-cinema:notes:v1`입니다. 기존 작품 ID와 저장 형식을 유지합니다. 찜과 저장한 메모는 localStorage에 남으며 보관함은 두 데이터의 합집합입니다.

찜과 저장한 메모는 해당 기기·브라우저에만 남고 브라우저 데이터를 지우면 사라집니다. 다른 기기·계정과의 동기화, 회원가입·로그인, 공개 게시물, 영상 재생·예매·결제, 개인화 API·서버 DB는 구현 범위에 없습니다.
