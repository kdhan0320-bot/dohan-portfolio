# 잔상관 · JANSANG CINEMA

가상 단편 영화 6편을 발견하고, 찜하고, 개인 감상 노트를 남기는 반응형 영화 탐색 웹입니다. HTML/CSS/Vanilla JavaScript로 만든 포트폴리오 콘셉트이며 실제 영상·상영·예매 서비스는 아닙니다.

## 2026-09-28 영화 중심 개편

이전 버전은 풍경 중심의 가로 이미지와 추상적인 테마가 반복되어 영화 서비스보다 감성 이미지 모음처럼 읽혔습니다. 정렬과 대비 보정만으로는 정체성이 충분히 드러나지 않는다는 피드백에 따라 다음을 바꿨습니다. 이는 디자인 판단이며 실제 사용자 조사 결과나 성과 수치가 아닙니다.

- 인물·관계·사건이 보이는 오리지널 영화 키아트: 2:3 포스터 6종과 와이드 대표 장면 1종. 실제 배우·상업 영화 포스터·브랜드 자산을 가져오지 않음.
- 대표 영화 → 세로 포스터 목록 → 기획전 → 대표 매거진 글 순으로 홈 재구성. 전체 글 세 편은 별도 매거진 화면으로 분리해 홈의 이미지 반복과 길이를 줄임.
- 홈/영화/기획전/매거진/나의 찜 다섯 메뉴, 검색과 이용안내 보조 기능. 내용 없는 이벤트·스토어·로그인 메뉴는 만들지 않음.
- 짙은 차콜·남색과 옅은 청회색 액션 색상을 유지하되, 영화 이미지는 장르별로 따뜻한 드라마·미스터리·SF·다큐의 색과 인물을 구분.
- 상세에 비공개 감상 노트 저장·수정·삭제 추가. 계정·서버·공개 게시판 없이 해당 브라우저에 저장.
- 모바일 제목 축약, 실제 이미지 위 텍스트 대비 보정, 중요 안내 12px, 주 메뉴·필터·찜·노트 삭제 조작 영역 최소44px.

## 화면과 흐름

| 메뉴 | 역할 | 다음 행동 |
| --- | --- | --- |
| 홈 `#home` | 대표 영화, 6편의 포스터, 세 기획전, 대표 글 하나 | 영화 상세 또는 기획전·매거진 |
| 영화 `#browse` | 제목·장르 검색, 다섯 분위기 필터, 결과·빈 상태 | 상세 → 찜 / 개인 노트 |
| 기획전 `#themes` | 고요한 밤 / 다정한 하루 / 낯선 세계, 선정 이유와 두 작품 | 두 작품 비교 → 상세 |
| 매거진 `#journal` | 장면·러닝타임·이야기의 공간에 관한 글 세 편 | 글 읽기 → 관련 영화 상세 |
| 나의 찜 `#saved` | 브라우저에 보관한 영화, 검색·필터·빈 상태 | 상세 → 노트 / 찜 해제 |

기획전 직접 주소는 `#themes/quiet`, `#themes/warmth`, `#themes/beyond`입니다. 브라우저 뒤로가기와 직접 진입을 지원합니다. 모달은 URL 경로가 아니며 Escape·닫기·배경 클릭으로 원래 화면에 돌아갑니다.

핵심 흐름은 세 가지입니다.

1. 영화 검색/필터 → 상세 정보 → 찜.
2. 기획전/매거진 → 관심 영화 상세 → 찜 또는 개인 노트.
3. 나의 찜 → 상세 → 기록 확인·수정·삭제.

## 실제 구현 범위

- 작품 이름·영문·장르·분위기·키워드 검색, 삭제·조건 초기화·빈 결과.
- 메뉴마다 검색 조건 유지, 검색 바로가기의 입력 포커스.
- 여섯 영화 상세와 세 기획전, 세 매거진 본문·관련 영화 연결.
- Native dialog, 키보드 포커스 순환/복귀, Escape·배경 클릭, 경로 이동 시 닫기. 매거진에서 영화로 이동하면 두 모달을 중첩하지 않으며 닫기 후 원래 매거진 카드로 복귀.
- 기존 `jansang-cinema:saved:v1` 키와 여섯 작품 ID를 유지해 기존 찜 데이터 보존.
- `jansang-cinema:notes:v1`: 작품별 최대280자 개인 노트. 빈값 검증, 저장·수정·삭제, 입력 중 상태 안내. 사용자 텍스트를 HTML로 실행하지 않음.
- 찜/노트 새로고침 유지, 다른 탭 변경 동기화, 손상 JSON·유효하지 않은 데이터 처리, 저장 차단 시 페이지 메모리 대체와 정확한 안내. 작성 중 노트를 다른 탭 변경이나 찜 갱신으로 덮어쓰지 않음.
- 로컬 저장 데이터는 기기·브라우저 간 계정 동기화가 아니며 브라우저 데이터 삭제 시 사라짐. 민감정보 입력을 요구하지 않음.

회원가입·로그인·공개 게시물 작성·영상 재생·예매·결제·개인화 API·서버 DB는 구현하지 않았습니다. 작동하는 것처럼 보이는 가짜 로그인·재생 완료 흐름을 제공하지 않습니다. 이용안내에서 실제 범위를 설명합니다.

## 소스와 자산

- `index.html`: 다섯 화면, 자체 SVG 심벌, 상세·매거진·안내 dialog.
- `css/style.css`: 반응형 그리드·시각 위계·키아트 크롭·상태·접근성 스타일.
- `js/main.js`: 가상 작품·기사 데이터, 경로, 검색, 찜, 노트, 포커스와 저장 처리.
- `assets/posters-v8/*.webp`: 내장 이미지 생성 도구로 생성한7개 영화 이미지. 전체 약645KB. 별도 영상·외부 CDN 요청 없음.
- `assets/ASSET_PROVENANCE.md`: 신규 전체 프롬프트, 치수·해시·처리 내역, 이전 자산 보존 기록.
- `assets/fonts/`: 기존 Pretendard Variable와 `OFL.txt`.

이전 자산 파일은 보존했으며 현재 화면에서는 새 포스터와 대표 장면만 참조합니다. CSS/JavaScript URL은 파일 SHA-256 앞8자리로 버전 관리합니다. 별도 빌드 없이 로컬 HTTP 서버로 실행할 수 있습니다. 배포 경로 `/ott-service/`와 저장소 폴더명은 유지합니다.

이번 Source of Truth는 이 HTML/CSS/JavaScript입니다. 별도 Figma 파일과 상위 포트폴리오의 소개글·썸네일은 수정하지 않았습니다.

## 포트폴리오와 Figma 정리 기준

취업용 표현은 **‘영화 탐색·개인 기록 UI / 반응형 웹 퍼블리싱’**이 적절합니다. 사용자 연구·매출·전환율·상용 OTT 운영 성과를 주장하지 않습니다. 이미지는 AI 활용임을 밝히고, 본인의 정보 구조·레이아웃·상태·반응형 구현과 검증을 구체적으로 설명합니다.

별도 Figma 정리 시 기존 프로젝트의 순서 `00 COVER / 01 SYSTEM / 02 READY 모바일 / 03 READY 반응형 / 04 MOTION / 05 SPEC_QA / 90 ARCHIVE`를 유지할 수 있습니다. READY에는 홈→영화 또는 기획전/매거진→상세→찜/노트의 화면을 놓고 빈 결과·빈 찜·저장 오류는 해당 화면 아래에 붙입니다. 긴 리서치 문서나 모든 화면을 잇는 복잡한 선 대신 두 핵심 과제(영화 찾기, 기록 남기기)를 나눠 보여줍니다. 이는 정리 기준이며 이번에 Figma를 수정한 것은 아닙니다.
