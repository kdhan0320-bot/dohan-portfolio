이번 범위는 잔상관 페이지와 해당 문서입니다. 공통 포트폴리오 소개와 별도 Figma 파일은 수정하지 않았습니다. 공개 반영은 기존 GitHub Pages 배포 흐름을 사용합니다. 아래 이전 버전의 검증 기록을 v16 결과로 재사용하지 않습니다.

## 현재 기능과 저장 방식

- 홈 목록은 전체 12편에 분위기와 러닝타임 조건을 적용합니다. 조건이 맞지 않으면 빈 결과와 초기화를 보여주고 포스터 목록·이동 버튼은 숨깁니다.
- 영화 찾기는 제목·영문 제목·장르·분위기·키워드를 검색합니다. 분위기와 러닝타임 조건을 결합하고 추천순·짧은 러닝타임순·제목순으로 정렬합니다.
- 포스터 캐러셀은 이전·다음, 마우스 드래그, 터치·가로 스크롤, 목록에 초점이 있을 때 좌우키·Home·End 이동을 제공합니다. 끝에 도달한 방향의 이동 버튼은 비활성 상태로 처리합니다.
- 찜은 북마크 버튼과 선택 상태로 표시합니다. 작품 상세에는 ‘찜하기 / 찜한 영화’ 텍스트를 함께 표시합니다. 저장한 메모가 있는 작품은 별도 배지를 표시합니다.
- 관심 메모는 작품별 최대 280자이며 빈값 검증, 저장·수정·삭제, 미저장 상태 안내를 제공합니다. 사용자 입력을 HTML 콘텐츠로 삽입하지 않습니다.
- 찜 키는 `jansang-cinema:saved:v1`, 메모 키는 `jansang-cinema:notes:v1`입니다. 기존 작품 ID와 저장 형식을 유지합니다. 찜과 저장한 메모는 localStorage에 남으며 보관함은 두 데이터의 합집합입니다.
- 저장 전 메모는 현재 탭의 메모리에만 남습니다. 닫기·Escape·배경 클릭·내부 화면 이동 후 이어 쓸 수 있지만 새로고침·탭 종료 시 사라지고 보관함 집계에 포함되지 않습니다.
- 저장한 데이터는 같은 출처의 다른 탭 변경과 동기화합니다. 작성 중인 메모는 보존하고 다른 탭의 저장본 변경을 안내합니다. 손상된 저장 데이터와 저장 공간 사용 불가에 대한 처리를 포함합니다.
- Native dialog의 닫기·Escape·배경 클릭, 초점 순환·복귀, 경로 변경 시 닫기를 처리합니다. 접힌 메모의 summary도 키보드 이동 대상입니다.

찜과 저장한 메모는 해당 기기·브라우저에만 남고 브라우저 데이터를 지우면 사라집니다. 다른 기기·계정과의 동기화, 회원가입·로그인, 공개 게시물, 영상 재생·예매·결제, 개인화 API·서버 DB는 구현 범위에 없습니다.

## 가상 콘텐츠 범위

영화명·장르·줄거리·러닝타임과 큐레이션은 포트폴리오용 가상 설정이며 이미지는 기존 AI 생성 자산을 사용합니다. 실제 인기·흥행 순위, 관객 수, 평점 데이터는 사용하지 않습니다. 차트 UI와 관련 데이터는 현재 버전에서 제거했습니다.

홈과 큐레이션의 주요 링크는 잔상관 내부의 작품 상세·영화 찾기·큐레이션·보관함으로 연결합니다. 실제 업체 요금·할인·외부 구매 링크·제휴 광고는 제공하지 않습니다. 푸터와 이용안내에서 프로토타입·가상 작품·AI 이미지·실제 재생 및 예매 미제공을 알립니다.
