# 잔상관 · JANSANG CINEMA

가상 단편 여섯 편을 검색·테마로 고르고 찜하는 반응형 영화 탐색 UI입니다. 실제 영상 서비스나 사용자 연구 성과를 주장하지 않는 포트폴리오 콘셉트입니다.

## 이번 시각 마감 — 2026-09-28

대표 이미지 안쪽 테두리는 본문 여백과 달랐고, 기존 배경 사선은 카드 정렬과 무관했습니다. 테두리·사선·기울어진 장식 사진을 화면에서 제외하고, 하나의 본문 그리드와 새 필름 이미지로 정리했습니다.

- 중앙은 어둡게 비우고 외곽에 필름과 푸른 빛을 배치한 전용 생성 이미지 추가. 이미지 자체 높이에 맞춘 페이드로 긴 화면에서도 배경 끝이 드러나지 않게 처리.
- 테마 제목과 카드 상단 정렬. 큰 숫자와 반복 장식을 줄이고 작품 이미지는 덜 세로로 잘리도록 조정. 바다 작품의 집과 불빛이 보이게 크롭 위치 보정.
- 모바일의 작은 장식 영문을 숨기고, 배경과 겹치는 테마·필터 글자에는 어두운 바탕 적용.
- 앞서 만든 네 메뉴와 실제 클라이언트 기능은 유지. 배경은 클릭·포커스를 받지 않음.

## 네 메뉴의 역할

이전의 대표작 → 전체 목록 두 구간은 단순했지만, 홈과 탐색의 역할이 겹치고 서비스 내 이동 경로가 부족했습니다. 배경 장식만 더하는 대신 네 메뉴에 서로 다른 역할을 부여했습니다.

| 메뉴 | 내용 | 다음 행동 |
| --- | --- | --- |
| 홈 `#home` | 대표작 한 편 + 테마 미리보기 세 개 | 작품 정보 또는 테마 선택 |
| 작품 `#browse` | 작품 6편, 분위기 필터, 검색 | 상세 확인 → 찜 |
| 테마 `#themes` | 고요한 밤 / 다정한 하루 / 낯선 세계, 테마마다 두 작품 | 선정 이유 확인 → 작품 선택 |
| 찜한 작품 `#saved` | 이 브라우저에 저장한 목록, 빈 상태 | 다시 확인하거나 찜 해제 |

테마별 주소는 `#themes/quiet`, `#themes/warmth`, `#themes/beyond`입니다. 브라우저 뒤로가기와 직접 주소 진입을 지원합니다. 전체 작품 수가 적으므로 신작·인기 순위·장르별 별도 메뉴는 만들지 않았습니다.

## 시각디자인과 읽기 순서

- 공통: 짙은 청회색 배경, 옅은 블루 선택 상태, 로컬 Pretendard Variable. 메뉴는 글자 굵기와 밑줄, 선택 필터는 색과 굵기로 구분합니다.
- 홈: 넓은 장면 → 대표작 제목 → 작품 살펴보기/찜하기 → 세 테마 미리보기. 별도 테두리 없이 장면을 넓게 보여주고, 아래 테마 구간의 필름 소재로 영화관의 인상을 이어갑니다.
- 작품: 제목·짧은 안내 → 검색/필터 → 결과 수 → 작품 카드. 데스크톱 3열, 모바일 2열. 작은 화면의 장르·시간은 세로로 정리해 찜 버튼과 겹치지 않게 했습니다.
- 테마: 세 가지 선택 → 짧은 테마 설명 → 정사각형에 가까운 두 작품. 데스크톱은 설명과 작품의 상단을 맞추고, 모바일은 위아래로 배치합니다.
- 모바일: 로고·검색과 네 메뉴를 두 줄로 분리해 메뉴를 숨기지 않습니다. 주요 메뉴·찜 버튼은 최소 44px 조작 높이입니다.
- 차별성: 영화의 장면, 와이드 화면, 편집형 큐레이션과 필름 소재를 중심에 둡니다. 고른시선의 유리·굴절, 갈피록의 종이·리본, 카페의 따뜻한 생활 이미지와 구분합니다. 개인 성향이나 퍼스널컬러가 사용성을 보장한다고 주장하지 않습니다.

| 토큰 | 값 |
| --- | --- |
| 배경 / 본문 | `#101820` / `#EDF2F8` |
| 보조 정보 | `#B2C0D0` |
| 강조 / 강조 위 글자 | `#C2D7EF` / `#162535` |

| 움직임 | 짧은 호버 전환, 동작 줄이기 설정 시 변형 해제 |

## 구현한 기능

- 작품 제목·영문·장르·분위기·키워드 검색, 검색어 삭제, 빈 결과, 조건 초기화.
- 분위기 전체/잔잔한/따뜻한/미스터리/새로운 세계 필터.
- 세 테마별 작품 두 편과 총 러닝타임, 테마 선택 상태와 직접 링크.
- 메뉴 이동 후 작품·찜 목록의 검색 조건 유지. 헤더 검색은 전체 작품으로 이동하며 입력창에 포커스.
- 작품 상세 6개, 짧은 줄거리, native dialog, 닫기·돌아가기·Escape·배경 클릭.
- 팝업 키보드 포커스 순환과 복귀. 경로 이동 시 열려 있던 팝업 닫기.
- 홈·테마·작품·상세의 찜 상태 동기화. 새로고침 유지와 다른 탭의 storage event 반영.
- 저장 공간 차단 시 현재 페이지 메모리로 동작하고 유지되지 않는다는 안내. 손상된 JSON 및 유효하지 않은 작품 ID 처리.
- 저장 상태는 글자·색·aria-pressed로 표시. 알림은 열린 dialog 안에 배치해 가려지지 않도록 처리.

회원가입·로그인·아이디/비밀번호 입력·게시물 작성·영상 재생·결제·개인화 추천 API·서버/DB 연동은 제공하지 않습니다. 계정 정보를 수집하거나 가짜 완료 화면을 보여주지 않습니다. 찜은 계정 데이터가 아니라 브라우저 저장 데이터입니다.

## 소스와 자산

HTML, CSS, Vanilla JavaScript이며 별도 빌드·설치가 필요 없습니다. 이 디렉터리를 로컬 HTTP 서버로 열면 됩니다. `/ott-service/` 배포 경로와 `OTT Service` 폴더명은 유지합니다.

- `index.html`: 네 화면의 구조, 자체 SVG symbol, 상세·안내 dialog.
- `css/style.css`: 토큰, 메뉴, 홈/작품/테마/찜, 상태, 반응형.
- `js/main.js`: 가상 작품·테마 데이터, 경로, 검색, 찜, 저장, 포커스.
- `assets/cinema-film-atmosphere.webp`: 이번 마감에서 신규 생성한 필름 배경, 1672×941 / 34,528 bytes. 외부 입력 이미지·영화 스틸·인물·브랜드 참조 없음. 이전 `cinema-atmosphere.svg`는 보존하지만 화면에서 참조하지 않음.
- `assets/stills/*.webp`: 앞선 작업에서 생성한 가상 장면 6종을 그대로 사용. 바이트 변경 없이 CSS 크롭만 조정.
- `assets/ASSET_PROVENANCE.md`: 생성 프롬프트·해시·출처·라이선스 기록.
- `assets/fonts/`: 기존 Pretendard Variable, `OFL.txt` 유지.

이번 수정의 Source of Truth는 이 HTML/CSS/JavaScript입니다. 별도 Figma 파일을 만들거나 수정하지 않았습니다. 상위 포트폴리오의 소개글·썸네일은 이 프로젝트 내부 수정에 포함하지 않았습니다.

## 취업용 설명과 화면 배열

‘영화 탐색 UI 콘셉트 / 반응형 웹 퍼블리싱’으로 소개할 수 있습니다. 메인 포트폴리오 설명은 대표 화면 → 기존 문제 → 네 메뉴의 역할 → 핵심 흐름과 상태 → 구현 범위 순서가 적절합니다. 실제 사용자 연구·전환율 개선·상용 OTT 운영 실적으로 표현하지 않습니다.

Figma로 별도 정리한다면 기존 프로젝트와 맞춰 `00 COVER / 01 SYSTEM / 02 READY 모바일 / 03 READY 반응형 / 04 MOTION / 05 SPEC_QA / 90 ARCHIVE`를 권장합니다. READY에는 홈 → 작품 또는 테마 → 상세 → 찜 순서로 화면을 나열하고, 빈 결과·빈 찜은 관련 화면 바로 아래에 배치합니다. 긴 프로세스 문서 대신 대표 흐름 두 개(검색으로 찾기, 테마로 고르기)와 실제 상태를 보여주는 구성입니다. 이는 정리안이며 이번에 Figma를 수정했다는 뜻이 아닙니다.
