# 잔상관 · JANSANG CINEMA

가상 단편 영화 12편을 소개하고, 관심 작품을 찜하고, 개인 영화 노트를 남기는 반응형 영화 발견 웹입니다. HTML/CSS/Vanilla JavaScript로 만든 포트폴리오 콘셉트입니다. 영화·차트·프로모션은 가상 설정입니다. 실제 영상·극장 예매·할인·결제는 제공하지 않습니다.

## 2026-10-06 포트폴리오 범위·시각 마감 (v14)

- 메뉴를 **영화 / 기획전 / 매거진 / 차트·이벤트 / 내 보관함**으로 정리했습니다. 로고는 홈으로 연결됩니다.
- 실제 개봉작·관객 수·외부 OTT 혜택·공식 서비스 링크를 화면에서 제거했습니다. 가상 작품 5편을 임의 순서로 배치하고, 실제 집계와 무관한 포트폴리오 예시임을 차트 가까이에 표시합니다.
- 밝은 청색 차트와 라벤더색 가상 OTT 프로모션으로 짙은 포스터 구간 사이의 시각적 구분을 줍니다. 기존 살구색 주말 기획전·개인 노트 캠페인은 내부 화면으로 연결합니다.
- ‘첫 달 30%’는 할인 배너 디자인 예시입니다. 클릭하면 가상 설정 안내와 영화 목록 진입만 제공하는 내부 미리보기를 엽니다. 실제 상품·제휴·쿠폰·가입·결제는 없습니다.
- 장식 화살표를 제거하고 필요한 이동 링크는 외곽선 버튼으로 정돈했습니다. 화살표 아이콘은 포스터 캐러셀의 이전·다음 두 곳에만 남깁니다.
- 작품 12편과 기존 이미지·글꼴·저장 키는 유지합니다. 외부 영화 이미지나 브랜드 자산을 추가하지 않았습니다.

### 검증 범위 (v14)

- Chromium 153에서 변경 관련 기능 7개 군 통과: 전체 경로의 외부 링크·화살표, 차트 8개 상세 진입·초점 복귀, 프로모션 열기·닫기·Escape·배경 클릭·Tab 순환, 영화 목록 이동·초점·뒤로가기, 4개 폭의 dialog, 찜 저장·새로고침·보관함·삭제, 390/1440px 캐러셀 양끝.
- 320/390/768/1440px × 홈·차트/이벤트·기획전·매거진 16개 배치 확인. 페이지 가로 넘침·중복 ID·깨진 이미지·44px 미만 조작 대상·브라우저 JS 오류 없음. 의도된 포스터 가로 스크롤은 제외합니다.
- 실제 로드된 글꼴·이미지로 만든 PNG에서 뉴스 1440/320px, 프로모션 390px, 홈 1440/390px, 기획전 768px, 매거진 320px의 정렬·줄바꿈을 검토했습니다.
- 320/390/1440px의 홈·차트/이벤트·프로모션에서 텍스트 208개 표본을 실제 배경 픽셀과 비교했습니다. 크기별 대비 기준 미달 0개. 일반 텍스트 최소 4.66:1, 큰 글자 최소 4.14:1. 초기 측정에 포함된 모달 뒤 비활성 화면은 제외하고 보이는 모달 텍스트를 다시 측정했습니다. 전체 WCAG 적합성 인증은 아닙니다.
- JavaScript 구문·Prettier·diff 공백 검사. 도구는 저장소 밖에서 실행했고 프로젝트 package·lockfile·workflow는 변경하지 않았습니다.

위는 현재 수정 범위의 Chromium 검사입니다. 실제 iOS/Safari/Firefox·스크린리더·사용자 과제 실험과 회원가입·로그인·결제는 검증하지 않았습니다. 계정·결제는 구현 범위 밖이며, 개인 노트의 전체 CRUD·다중 탭 테스트는 아래 v13 이력과 구분합니다.

기획전 직접 주소는 `#themes/quiet`, `#themes/warmth`, `#themes/beyond`입니다. 경로 변경은 브라우저 뒤로가기와 연결합니다. 영화·매거진 상세는 경로와 별도의 dialog이며 닫으면 기존 화면으로 돌아갑니다.

핵심 과제는 **영화 찾기 → 소개 읽기 → 찜**, **관심 영화 → 개인 노트 → 내 보관함에서 다시 찾기**입니다. 차트·이벤트의 작품과 캠페인도 잔상관 안의 상세·미리보기·기획전으로 연결합니다.

## 구현 범위와 저장 방식

- 제목·영문·장르·분위기·키워드 검색, 조건 초기화와 빈 결과를 제공합니다.
- 가상 영화 12편 상세, 기획전 3개, 매거진 4편과 관련 작품을 연결합니다.
- 포스터 캐러셀의 양 끝 상태, 북마크 상태, 정렬·검색·분위기·보관함 분류를 UI에 표시합니다.
- Native dialog를 사용합니다. Escape·배경 클릭·닫기, 포커스 순환·복귀, 경로 이동 시 닫기 처리를 포함합니다.
- 찜 키는 `jansang-cinema:saved:v1`, 노트 키는 `jansang-cinema:notes:v1`입니다. 기존 6편의 ID를 유지합니다.
- 작품별 개인 노트는 최대 280자입니다. 빈값 검증, 저장·수정·삭제, 입력 중 안내, 사용자 텍스트의 HTML 실행 방지 처리를 포함합니다.
- 로컬 저장의 새로고침 유지, 다른 탭 변경 동기화, 손상 데이터 처리, 저장 불가 시 페이지 메모리 대체, 작성 중 충돌 안내를 포함합니다.

노트는 해당 기기·브라우저에만 저장되며 브라우저 데이터를 지우면 사라집니다. 회원가입·로그인·공개 게시물·영상 재생·예매·결제·개인화 API·서버 DB는 구현 범위에 없습니다. 개인 노트와 공개 게시물 기능을 같은 것으로 설명하지 않습니다.

## 가상 콘텐츠와 프로모션 범위

영화명·줄거리·러닝타임, 기획전·매거진, 차트 순위와 할인 프로모션은 포트폴리오용 가상 설정입니다. 차트는 이용자 데이터·관객 수·평점·실제 흥행 실적을 반영하지 않습니다. ‘가상 작품으로 구성한 포트폴리오용 예시 순위’를 화면에 표시합니다.

‘첫 달 30%’는 가상 OTT 프로모션의 시각 디자인 예시입니다. 배너·프로모션 화면·미리보기에서 실제 할인·가입·결제가 없음을 알립니다. 실제 업체명·요금·외부 구매 링크를 사용하지 않으며, 실제 제휴나 광고를 주장하지 않습니다. 주말 기획전과 개인 노트 배너도 내부 탐색 기능으로 연결합니다.

공식 사이트 링크나 사실 정보가 포트폴리오라는 이유만으로 일괄 금지되는 것은 아닙니다. 이번 수정은 사용자가 요청한 가상 서비스의 범위를 명확히 하고 실제 혜택과 혼동하지 않도록 콘텐츠를 통일한 것입니다.

잔상관은 인물·사건이 있는 영화 포스터와 장르별 색차, 와이드 장면을 중심으로 다른 프로젝트와 구분합니다. 차분한 청색 UI는 사용자가 요청한 이미지 방향을 반영한 디자인 선택입니다. 성격·퍼스널컬러를 검증한 결과나 채용 성과의 증거로 제시하지 않습니다.

- `index.html`: 홈과 다섯 메뉴 화면, 자체 SVG 심벌, 영화·매거진·안내·프로모션 dialog, 가상 설정 안내.
- `css/style.css`: 반응형 레이아웃, 포스터 제목과 크롭, 입력·선택·포커스 상태.
- `js/main.js`: 가상 작품·기획전·기사, 경로·검색·정렬·캐러셀·찜·노트·저장 처리.
- `assets/posters-v8/`: 기존 작품 포스터 6장 및 이전 대표 이미지 보존.
- `assets/posters-v13/`: 신규 작품 포스터 6장과 `bluehour-hero.webp`.
- `assets/campaigns-v13/film-weekend.webp`: 자체 기획전 배너.
- `assets/ASSET_PROVENANCE.md`: 신규 이미지 8장의 전체 생성 프롬프트·치수·해시·처리 기록, 기존 자산과 글꼴 라이선스.

외부 영화 이미지·상용 포스터·배우 사진·브랜드 로고를 새로 가져오지 않았습니다. 생성 이미지 사용과 출처 기록은 법적 무위험이나 독점권을 보증하지 않습니다. 이전 자산·글꼴 파일 및 라이선스 고지는 보존합니다.

별도 빌드 없이 로컬 HTTP 서버로 실행합니다. 배포 경로 `/ott-service/`와 저장소 폴더명은 유지합니다. 현재 기준 소스는 이 HTML/CSS/JavaScript이며 별도 Figma 파일은 이번 수정 대상이 아닙니다.

## 포트폴리오와 Figma 정리 기준

취업용 설명은 **영화 발견·개인 기록 UI / 반응형 웹 퍼블리싱**입니다. 가상 작품과 AI 이미지 활용 범위, 본인의 정보 구조·시각 체계·상태·반응형 구현, 실제 수행한 검증을 구분합니다. 사용자 연구·전환율·매출·상용 OTT 운영 성과를 주장하지 않습니다.

별도 Figma 정리 시 `00 COVER / 01 SYSTEM / 02 READY 모바일 / 03 READY 반응형 / 04 MOTION / 05 SPEC_QA / 90 ARCHIVE`를 사용할 수 있습니다. 영화 찾기와 기록 남기기 두 과제로 화면을 묶고, 빈 결과·빈 보관함·저장 오류는 해당 화면 아래에 붙입니다. 긴 설명과 전체 화면을 잇는 복잡한 선 대신 각 선택의 다음 화면을 보여주는 정리 기준입니다. 이번 작업에서 Figma를 수정했다는 의미는 아닙니다.

## 이전 개편·검증 이력 — v13 (2026-10-06)
